# 背包问题

f[i][j] : 前i个物品，总体积是j的情况下，总价值是多少

1. 不选第i件物品 : f[i][j] = f[i-1][j]
2. 选第i件物品 : f[i][j] = f[i-1][j-w[i]] + v[i]
f[i][j] = max(1.,2.)

f[0][0] = 0

dp[i][j] = max(dp[i−1][j], dp[i−1][j−w[i]]+v[i]) // j >= w[i]
dp[i][j]的值只与dp[i-1][0,...,j-1]

// 01背包问题伪代码(空间优化版)
dp[0,...,W] = 0
for i = 1,...,N
    for j = W,...,w[i] // 必须逆向枚举!!!
        dp[j] = max(dp[j], dp[j−w[i]]+v[i])
