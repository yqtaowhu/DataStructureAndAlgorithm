## 冒泡排序

### 算法思想
重复地遍历待排序数组，比较相邻元素并在顺序错误时交换它们。较大的元素会像气泡一样"浮"到数组末尾。

### 时间复杂度
- 最好情况：O(n) - 已排序数组，使用优化标志
- 最坏情况：O(n²)
- 平均情况：O(n²)

### 空间复杂度：O(1)

### 稳定性：稳定

### C++ 实现

```cpp
void bubbleSort(vector<int>& arr) {
    int n = arr.size();
    bool swapped; // 优化标志
    
    for (int i = 0; i < n - 1; i++) {
        swapped = false;
        for (int j = 0; j < n - i - 1; j++) {
            if (arr[j] > arr[j + 1]) {
                swap(arr[j], arr[j + 1]);
                swapped = true;
            }
        }
        // 如果没有发生交换，说明已经有序
        if (!swapped) break;
    }
}
```

### 面试要点
- **优化技巧**：添加 `swapped` 标志检测是否已排序
- **适用场景**：数据量小、对稳定性有要求
- **缺点**：效率低，不适合大规模数据

## 插入排序

### 算法思想
将数组分为已排序和未排序两部分，每次从未排序部分取出一个元素，插入到已排序部分的正确位置。

### 时间复杂度
- 最好情况：O(n) - 已排序数组
- 最坏情况：O(n²)
- 平均情况：O(n²)

### 空间复杂度：O(1)

### 稳定性：稳定

### C++ 实现

```cpp
void insertionSort(vector<int>& arr) {
    int n = arr.size();
    
    for (int i = 1; i < n; i++) {
        int key = arr[i]; // 要插入的元素
        int j = i - 1;
        
        // 将大于 key 的元素向后移动
        while (j >= 0 && arr[j] > key) {
            arr[j + 1] = arr[j];
            j--;
        }
        arr[j + 1] = key; // 插入到正确位置
    }
}
```

### 面试要点
- **特点**：对于小规模或基本有序的数组非常高效
- **应用**：常作为其他排序算法（如快速排序）的优化手段
- **稳定性**：稳定排序

## 快速排序

### 算法思想
采用分治法策略：
1. 选择一个基准值（pivot）
2. 分区操作：将小于基准值的放左边，大于的放右边
3. 递归地对左右子数组进行快速排序

### 时间复杂度
- 最好情况：O(n log n)
- 最坏情况：O(n²) - 已排序数组且选第一个为 pivot
- 平均情况：O(n log n)

### 空间复杂度：O(log n) - 递归栈空间

### 稳定性：不稳定

### C++ 实现

#### 基础版本

```cpp
void quickSort(vector<int>& arr, int left, int right) {
    if (left >= right) return;
    
    int pivotIndex = partition(arr, left, right);
    quickSort(arr, left, pivotIndex - 1);
    quickSort(arr, pivotIndex + 1, right);
}

int partition(vector<int>& arr, int left, int right) {
    int pivot = arr[left]; // 选择第一个元素作为基准
    int i = left + 1, j = right;
    
    while (i <= j) {
        while (i <= j && arr[i] <= pivot) i++;
        while (i <= j && arr[j] > pivot) j--;
        if (i < j) swap(arr[i], arr[j]);
    }
    
    swap(arr[left], arr[j]);
    return j;
}
```

#### 双指针交换版本（更简洁）

```cpp
void quickSort(vector<int>& arr, int left, int right) {
    if (left >= right) return;
    
    int pivot = arr[left];
    int i = left, j = right;
    
    while (i < j) {
        // 从右向左找小于 pivot 的元素
        while (i < j && arr[j] >= pivot) j--;
        if (i < j) arr[i++] = arr[j];
        
        // 从左向右找大于 pivot 的元素
        while (i < j && arr[i] <= pivot) i++;
        if (i < j) arr[j--] = arr[i];
    }
    
    arr[i] = pivot;
    
    quickSort(arr, left, i - 1);
    quickSort(arr, i + 1, right);
}
```

#### 三数取中优化（避免最坏情况）

```cpp
int medianOfThree(vector<int>& arr, int left, int right) {
    int mid = left + (right - left) / 2;
    
    if (arr[left] > arr[mid]) swap(arr[left], arr[mid]);
    if (arr[left] > arr[right]) swap(arr[left], arr[right]);
    if (arr[mid] > arr[right]) swap(arr[mid], arr[right]);
    
    return mid; // 返回中间值的位置
}

void quickSortOptimized(vector<int>& arr, int left, int right) {
    if (left >= right) return;
    
    // 三数取中选择 pivot
    int pivotIndex = medianOfThree(arr, left, right);
    swap(arr[left], arr[pivotIndex]);
    
    int pivotPos = partition(arr, left, right);
    quickSortOptimized(arr, left, pivotPos - 1);
    quickSortOptimized(arr, pivotPos + 1, right);
}
```

### 面试要点
- **核心操作**：partition 分区函数
- **优化技巧**：
  - 三数取中选择 pivot
  - 小区间使用插入排序
  - 三路快排处理大量重复元素
- **空间复杂度**：递归调用栈 O(log n)
- **应用场景**：通用排序，性能最好

## 堆排序

### 算法思想
利用堆（二叉堆）这种数据结构：
1. 构建最大堆
2. 将堆顶元素（最大值）与末尾元素交换
3. 调整剩余元素为最大堆
4. 重复步骤 2-3，直到堆大小为 1

### 时间复杂度
- 最好/最坏/平均：O(n log n)

### 空间复杂度：O(1)

### 稳定性：不稳定

### C++ 实现

```cpp
void heapSort(vector<int>& arr) {
    int n = arr.size();
    
    // 1. 构建最大堆
    for (int i = n / 2 - 1; i >= 0; i--) {
        heapify(arr, n, i);
    }
    
    // 2. 逐个提取元素
    for (int i = n - 1; i > 0; i--) {
        swap(arr[0], arr[i]); // 将最大值移到末尾
        heapify(arr, i, 0);   // 调整堆
    }
}

// 堆化操作：维护最大堆性质
void heapify(vector<int>& arr, int n, int i) {
    int largest = i;          // 当前节点
    int left = 2 * i + 1;     // 左孩子
    int right = 2 * i + 2;    // 右孩子
    
    // 如果左孩子存在且大于父节点
    if (left < n && arr[left] > arr[largest]) {
        largest = left;
    }
    
    // 如果右孩子存在且大于当前最大
    if (right < n && arr[right] > arr[largest]) {
        largest = right;
    }
    
    // 如果不相等，需要交换并继续堆化
    if (largest != i) {
        swap(arr[i], arr[largest]);
        heapify(arr, n, largest);
    }
}
```

### 面试要点
- **堆的性质**：父节点 ≥ 子节点（最大堆）
- **索引关系**：父节点 i，左孩子 2i+1，右孩子 2i+2
- **优势**：时间复杂度稳定 O(n log n)，空间复杂度 O(1)
- **应用场景**：Top K 问题、优先队列

## 归并排序

### 算法思想
采用分治法：
1. 分解：将数组分成两半
2. 解决：递归排序两个子数组
3. 合并：合并两个已排序的子数组

### 时间复杂度
- 最好/最坏/平均：O(n log n)

### 空间复杂度：O(n) - 需要临时数组

### 稳定性：稳定

### C++ 实现

```cpp
void mergeSort(vector<int>& arr, int left, int right) {
    if (left >= right) return;
    
    int mid = left + (right - left) / 2;
    mergeSort(arr, left, mid);      // 排序左半部分
    mergeSort(arr, mid + 1, right); // 排序右半部分
    merge(arr, left, mid, right);   // 合并
}

void merge(vector<int>& arr, int left, int mid, int right) {
    int i = left, j = mid + 1, k = 0;
    vector<int> temp(right - left + 1);
    
    // 合并两个有序数组
    while (i <= mid && j <= right) {
        if (arr[i] <= arr[j]) {
            temp[k++] = arr[i++];
        } else {
            temp[k++] = arr[j++];
        }
    }
    
    // 复制剩余元素
    while (i <= mid) temp[k++] = arr[i++];
    while (j <= right) temp[k++] = arr[j++];
    
    // 复制回原数组
    for (int i = 0; i < k; i++) {
        arr[left + i] = temp[i];
    }
}
```

### 面试要点
- **分治思想**：典型的应用示例
- **稳定性**：稳定的排序算法
- **空间开销**：需要 O(n) 额外空间
- **应用场景**：链表排序、外部排序、需要稳定性的场景

## 选择排序

### 算法思想
每次从未排序部分选择最小（或最大）的元素，放到已排序部分的末尾。

### 时间复杂度
- 最好/最坏/平均：O(n²)

### 空间复杂度：O(1)

### 稳定性：不稳定

### C++ 实现

```cpp
void selectionSort(vector<int>& arr) {
    int n = arr.size();
    
    for (int i = 0; i < n - 1; i++) {
        int minIndex = i;
        
        // 找到最小元素的索引
        for (int j = i + 1; j < n; j++) {
            if (arr[j] < arr[minIndex]) {
                minIndex = j;
            }
        }
        
        // 交换
        if (minIndex != i) {
            swap(arr[i], arr[minIndex]);
        }
    }
}
```

### 面试要点
- **简单直观**：最容易理解的排序算法之一
- **交换次数少**：最多 n-1 次交换
- **性能差**：无论数据如何都是 O(n²)

## 希尔排序

### 算法思想
插入排序的改进版：
1. 选择间隔序列，将数组分组
2. 对每组进行插入排序
3. 逐渐缩小间隔，直到间隔为 1

### 时间复杂度
- 取决于间隔序列选择
- 最好：O(n log n)
- 最坏：O(n²)

### 空间复杂度：O(1)

### 稳定性：不稳定

### C++ 实现

```cpp
void shellSort(vector<int>& arr) {
    int n = arr.size();
    
    // 初始间隔为 n/2，每次减半
    for (int gap = n / 2; gap > 0; gap /= 2) {
        // 对每个子序列进行插入排序
        for (int i = gap; i < n; i++) {
            int temp = arr[i];
            int j = i;
            
            // 在子序列中进行插入排序
            while (j >= gap && arr[j - gap] > temp) {
                arr[j] = arr[j - gap];
                j -= gap;
            }
            arr[j] = temp;
        }
    }
}
```

### 面试要点
- **插入排序的优化**：通过提前移动元素提高效率
- **间隔序列**：影响性能的关键
- **不稳定性**：相同元素可能改变相对顺序

## 面试常见问题

### 1. 为什么快速排序在实际应用中表现最好？
- 常数因子小，实际运行速度快
- 原地排序，空间效率高
- 局部性好，缓存友好

### 2. 什么情况下应该使用堆排序？
- 需要稳定的 O(n log n) 时间复杂度
- 空间受限（O(1) 额外空间）
- Top K 问题

### 3. 归并排序和快速排序的区别？
- 归并：稳定，需要 O(n) 空间，适合链表
- 快速：不稳定，O(log n) 空间，适合数组

### 4. 如何实现稳定的快速排序？
- 使用归并排序的思路
- 增加记录原始位置的字段
- 使用平衡树等数据结构

### 5. 什么是原地排序？
- 只需要常数额外空间的排序算法
- 包括：冒泡、插入、选择、快速、堆、希尔排序
- 不包括：归并排序

    for (int i = 1; i < arr.size(); i++) {
        if (arr[i - 1] > arr[i]) return false;
    }
    return true;
}

    vector<int> arr = {5, 2, 9, 1, 5, 6};
