# 字符串 C++ 模板（简单易记版）

## 核心思想：字符串 = 带语义的数组

字符串题 90% 能归约到三个已有套路：
1. **双指针**（回文验证、翻转、子序列）
2. **中心扩展 / 动态规划**（回文子串）
3. **哈希计数**（异位词、映射规律）

外加一个专属硬骨头：**KMP**（子串查找）。

> 字符串的基础运算见 [字符串的运算.md](字符串的运算.md)，本篇聚焦高频模板。

## 万能模板一：中心扩展（回文子串）

```cpp
// 示例：5. 最长回文子串（647 回文子串计数 同款）
string longestPalindrome(string s) {
    int start = 0, len = 0;
    auto expand = [&](int l, int r) {       // 从中心向两边扩
        while (l >= 0 && r < (int)s.size() && s[l] == s[r]) { l--; r++; }
        return make_pair(l + 1, r - 1);     // 收缩回来一步才是回文区间
    };
    for (int i = 0; i < (int)s.size(); i++) {
        auto [l1, r1] = expand(i, i);       // 奇数长度：中心是一个字符
        auto [l2, r2] = expand(i, i + 1);   // 偶数长度：中心是间隙
        if (r1 - l1 + 1 > len) { start = l1; len = r1 - l1 + 1; }
        if (r2 - l2 + 1 > len) { start = l2; len = r2 - l2 + 1; }
    }
    return s.substr(start, len);
}
```

**只需记住三句话：**
1. 共 `2n - 1` 个中心：`n` 个字符 + `n - 1` 个间隙
2. 奇偶各扩一次，谁长取谁
3. 求计数（647）就把"记录最长"改成"每次匹配成功计数 +1"

## 万能模板二：双指针（回文验证 / 翻转）

```cpp
// 示例：125. 验证回文串（跳过非字母数字）
bool isPalindrome(string s) {
    int l = 0, r = s.size() - 1;
    while (l < r) {
        while (l < r && !isalnum(s[l])) l++;    // 跳过无效字符
        while (l < r && !isalnum(s[r])) r--;
        if (tolower(s[l]) != tolower(s[r])) return false;
        l++; r--;
    }
    return true;
}

// 151. 翻转字符串里的单词：整体翻转 → 再逐词翻转 → 清理多余空格
// 344/186 反转字符串：对撞交换，最基础版
```

## 万能模板三：KMP（子串查找）

核心是 `next` 数组：**next[i] = 前 i 个字符中，最长的"相等前后缀"长度**。

```cpp
// 示例：28. 实现 strStr()
vector<int> buildNext(const string& p) {
    int m = p.size();
    vector<int> next(m, 0);              // next[0] 恒为 0
    for (int i = 1, len = 0; i < m; ) {
        if (p[i] == p[len]) next[i++] = ++len;  // 延长公共前后缀
        else if (len > 0)   len = next[len - 1]; // 回退到次长前后缀
        else                next[i++] = 0;        // 没得退，从 0 开始
    }
    return next;
}

int strStr(string s, string p) {
    if (p.empty()) return 0;
    vector<int> next = buildNext(p);
    for (int i = 0, j = 0; i < (int)s.size(); ) {
        if (s[i] == p[j]) { i++; j++; }
        else if (j > 0)   j = next[j - 1];   // 主串不回退！模式串回退
        else              i++;
        if (j == (int)p.size()) return i - j; // 匹配成功
    }
    return -1;
}
```

**要点：** KMP 的全部精髓就一句——**主串指针永不回退，失配时模式串按 next 回跳**。

## 万能模板四：哈希计数（映射 / 异位词）

```cpp
// 示例：205. 同构字符串（290. 单词规律 同款）—— 双向映射
bool isIsomorphic(string s, string t) {
    unordered_map<char, char> s2t, t2s;
    for (int i = 0; i < s.size(); i++) {
        if (s2t.count(s[i]) && s2t[s[i]] != t[i]) return false;
        if (t2s.count(t[i]) && t2s[t[i]] != s[i]) return false;
        s2t[s[i]] = t[i]; t2s[t[i]] = s[i];
    }
    return true;
}

// 242. 有效的字母异位词：int cnt[26] 一个加一个减，最后全为 0
```

> **双向映射是关键**：只查单向会漏掉"两个字符映射到同一个目标"的情况。
