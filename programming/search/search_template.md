## 核心思想：搜索三问

搜索本质是对「图 / 网格 / 状态」的系统性穷举，动手前先回答三个问题：

1. **节点是什么？** 网格是 `(i,j)`，图是编号，状态空间是一个字符串 / 棋盘。
2. **怎么不重复访问？** 网格直接改值或用 `visited`；图用 `color/vis`；状态用 `unordered_set`。
3. **DFS 还是 BFS？**
   - **DFS**（栈 / 递归）：一条路走到底 → 连通性、路径收集、拓扑、判环、回溯。
   - **BFS**（队列）：一层层扩散 → **最短步数 / 最少操作 / 层级信息 / 多源扩散**。

方向数组是网格类问题的标配（免写四个 if）：

```cpp
int dx[4] = {-1, 1, 0, 0}, dy[4] = {0, 0, -1, 1};              // 四连通：上下左右
int dx[8] = {-1,-1,-1,0,0,1,1,1}, dy[8] = {-1,0,1,-1,1,-1,0,1}; // 八连通（含对角）
```

## 模板一：网格 DFS（连通块 / Flood Fill）

```cpp
// 示例：200. 岛屿数量（130/695/733/1020/1254/1905/417 都是同款）
void dfs(vector<vector<char>>& grid, int i, int j) {
    // 1. 越界 / 不合法（也可换成 visited 数组判断）
    if (i < 0 || i >= grid.size() || j < 0 || j >= grid[0].size()
        || grid[i][j] != '1') return;

    grid[i][j] = '0';                    // 2. 进入格子立刻标记，否则死循环
    for (int d = 0; d < 4; d++)          // 3. 向四个方向扩散
        dfs(grid, i + dx[d], j + dy[d]);
}

int numIslands(vector<vector<char>>& grid) {
    int ans = 0;
    for (int i = 0; i < grid.size(); i++)
        for (int j = 0; j < grid[0].size(); j++)
            if (grid[i][j] == '1') { dfs(grid, i, j); ans++; }  // 找到一个连通块计一次数
    return ans;
}
```

**三句话记住：** ①函数开头判越界与不合法；②进格子立刻标记；③外层双循环找起点，一个连通块计一次。

**变体：** DFS 带返回值可统计面积 / 周长 / 是否满足条件（见 695、463、1905）。

## 模板二：网格 BFS（最短步数 / 多源）

```cpp
// 示例：994. 腐烂的橘子（多源 BFS：所有源头同时入队）
int orangesRotting(vector<vector<int>>& grid) {
    queue<pair<int,int>> q;
    int fresh = 0;
    for (int i = 0; i < grid.size(); i++)
        for (int j = 0; j < grid[0].size(); j++) {
            if (grid[i][j] == 2) q.push({i, j});   // 所有源头一起入队 = 超级源点
            if (grid[i][j] == 1) fresh++;
        }
    int minutes = 0;
    while (!q.empty() && fresh > 0) {
        int size = q.size(); minutes++;            // 一层 = 一步
        for (int s = 0; s < size; s++) {
            auto [x, y] = q.front(); q.pop();
            for (int d = 0; d < 4; d++) {
                int nx = x + dx[d], ny = y + dy[d];
                if (nx < 0 || nx >= grid.size() || ny < 0 || ny >= grid[0].size()
                    || grid[nx][ny] != 1) continue;
                grid[nx][ny] = 2; fresh--;         // 入队时标记！
                q.push({nx, ny});
            }
        }
    }
    return fresh == 0 ? minutes : -1;
}
```

**要点：** ① BFS 必须**入队时标记**（不是出队时），否则同一节点被重复入队；② `while` 每轮处理一整层，层数 = 最短步数。多源 BFS（542/994/1162）把所有源一次性入队即可。

## 模板三：图 / 状态空间 BFS（求最少操作数）

当「节点」不是格子而是一个**状态**（字符串、棋盘、数字组合）时，用 `unordered_set` 记录访问过的状态，其余与网格 BFS 完全一致。

```cpp
// 示例：752. 打开转盘锁 / 773. 滑动谜题 / 301. 删除无效的括号
int bfs(string start, string target) {
    unordered_set<string> vis; queue<string> q;
    q.push(start); vis.insert(start);
    int step = 0;
    while (!q.empty()) {
        int sz = q.size();
        for (int i = 0; i < sz; i++) {
            string cur = q.front(); q.pop();
            if (cur == target) return step;         // 第一次到达即最少步数
            for (string nxt : neighbors(cur))       // 生成所有合法后继状态
                if (!vis.count(nxt)) { vis.insert(nxt); q.push(nxt); }
        }
        step++;
    }
    return -1;
}
```

## 模板四：二分图染色（BFS / DFS 皆可）

```cpp
// 示例：785. 判断二分图 / 886. 可能的二分法
vector<int> color(n, 0);                    // 0 未染色，1/-1 两色
for (int i = 0; i < n; i++) {
    if (color[i]) continue;
    queue<int> q; q.push(i); color[i] = 1;
    while (!q.empty()) {
        int u = q.front(); q.pop();
        for (int v : g[u]) {
            if (!color[v]) { color[v] = -color[u]; q.push(v); }   // 相邻染异色
            else if (color[v] == color[u]) return false;          // 同色冲突 → 非二分图
        }
    }
}
```

## 模板五：图的邻接表 + 拓扑排序（判环 / 依赖顺序）

```cpp
// 建图：先想清楚边的方向！course -> 依赖它的课
vector<vector<int>> g(numCourses);
vector<int> indegree(numCourses, 0);
for (auto& p : prerequisites) { g[p[1]].push_back(p[0]); indegree[p[0]]++; }

// Kahn（BFS）：入度为 0 的先出队，出队即"完成"
queue<int> q;
for (int i = 0; i < n; i++) if (indegree[i] == 0) q.push(i);
int cnt = 0;
while (!q.empty()) {
    int u = q.front(); q.pop(); cnt++;      // 210：把 u 存进数组即拓扑序
    for (int v : g[u]) if (--indegree[v] == 0) q.push(v);
}
return cnt == n;    // 全部完成 = 无环；否则有环
```

**判环也可用 DFS 三色标记：** 白(未访问) / 灰(访问中) / 黑(已完成)，遇到灰色即有环。

## DFS 还是 BFS？一表定夺

| 需求 | 选择 | 原因 |
|------|------|------|
| 连通块个数 / 能否到达 | DFS | 只关心连通性，不用记层 |
| 最短步数 / 最少操作 | **BFS** | 层序 = 步数，第一次到达即最短 |
| 多个源头同时扩散 | 多源 BFS | 所有源先入队，等价超级源点 |
| 收集所有路径 / 所有方案 | DFS + 回溯 | 要保存完整路径 |
| 课程表 / 编译依赖 / 判环 | 拓扑排序 | Kahn(BFS) 或 DFS 三色标记 |
| 二分图 / 分组 | 染色 BFS/DFS | 相邻异色，冲突即否 |
| 状态最少变换次数 | 状态空间 BFS | 状态入 set 去重，层数即步数 |

## 记忆口诀

> **DFS 三步：判越界、先标记、四方扩散；BFS 三步：源头入队、入队标记、一层一步。**
> **要最短用 BFS，要路径用 DFS，有依赖找拓扑，能分组先染色，状态最少操作就 BFS + set 去重。**
