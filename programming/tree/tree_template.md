## 一、核心思想：递归三问

二叉树 90% 的题都是**递归**。动手前先问自己三个问题：

1. **返回值**：递归函数要给父节点返回什么？（`bool` / `int` / `TreeNode*` / 自定义结构体……）
2. **终止条件**：`root == nullptr` 时返回什么？
3. **单层逻辑**：拿到左右子树的结果后，当前节点怎么拼出答案？

再叠加一个方向判断，几乎所有题都能定位模板：

| 信息流向 | 位置 | 传递方式 | 典型场景 |
|----------|------|----------|----------|
| **自顶向下**（递） | 前序 | 用**参数**往下传 | 深度、路径和、根到叶数字、BST 区间校验 |
| **自底向上**（归） | 后序 | 用**返回值**往上传 | 高度、直径、平衡、最大路径和、删点、树形 DP |
| **逐层横向** | BFS | 用**队列**分层 | 层序、右视图、最小深度、每层最大值、完全性检验 |
| **有序性** | 中序 | 利用 BST 中序递增 | 验证 BST、第 k 小、最小差、恢复 BST、累加树 |

> 辨析：求「深度」用前序（一路 `+1` 传下去），求「高度」用后序（左右取 `max` 再 `+1` 传上来）。

## 二、六大万能模板

### 模板 1：递归遍历骨架（改一行 = 前/中/后序）

```cpp
void traverse(TreeNode* root, vector<int>& res) {
    if (root == nullptr) return;
    // res.push_back(root->val);   // 前序位置：进入节点时（自顶向下）
    traverse(root->left, res);
    // res.push_back(root->val);   // 中序位置：左子树处理完（BST 有序）
    traverse(root->right, res);
    // res.push_back(root->val);   // 后序位置：离开节点时（自底向上）
}
```

### 模板 2：迭代遍历（栈）

```cpp
// 中序迭代：一路压左链，弹出时处理，再转向右子树（94/173/230 通用）
vector<int> inorderTraversal(TreeNode* root) {
    vector<int> res;
    stack<TreeNode*> st;
    while (root || !st.empty()) {
        if (root) { st.push(root); root = root->left; }
        else {
            root = st.top(); st.pop();
            res.push_back(root->val);   // 换成前/后序处理即可
            root = root->right;
        }
    }
    return res;
}
```

> 前序迭代：栈中**先压右再压左**；后序迭代：按「前序（先压左再压右）」遍历后 `reverse(res)`。
> Morris 遍历可做到 O(1) 空间（利用叶子节点的空右指针建线索），面试可作为加分项。

### 模板 3：层序遍历 BFS（queue + size 分层）

```cpp
// 102 层序；199 右视图 / 103 锯齿 / 111 最小深度 / 637 平均值 都是它的变体
vector<vector<int>> levelOrder(TreeNode* root) {
    vector<vector<int>> res;
    queue<TreeNode*> q;
    if (root) q.push(root);
    while (!q.empty()) {
        int size = q.size();            // 本层节点数，必须先取！
        vector<int> level;
        for (int i = 0; i < size; i++) {
            TreeNode* node = q.front(); q.pop();
            level.push_back(node->val);
            if (node->left)  q.push(node->left);
            if (node->right) q.push(node->right);
        }
        res.push_back(level);
    }
    return res;
}
```

**要点：** `int size = q.size()` 固定本层元素个数，内层 `for` 只处理这一层——这就是「逐层」的全部秘密。求**最小深度 / 最短步数**时，BFS 第一次到达叶子即为答案，无需遍历全树。

### 模板 4：分解问题（后序拼答案）

```cpp
// 104 最大深度；543 直径 / 110 平衡 / 124 最大路径和 都是同款骨架
int maxDepth(TreeNode* root) {
    if (root == nullptr) return 0;          // 2. 终止条件
    int l = maxDepth(root->left);           // 3. 信任递归：左右子树答案
    int r = maxDepth(root->right);
    return max(l, r) + 1;                   // 4. 拼上当前节点
}
```

**要点：** 不要跳进递归细节，相信左右子树已返回正确答案，你只负责**当前层怎么组合**。若一个返回值不够用（既要高度又要更新答案），用**全局/引用变量**记录答案，返回值只传「单边贡献」。

### 模板 5：BST 中序有序性

```cpp
// BST 的中序遍历是严格递增序列——凡「BST + 大小/顺序/第 k」先想中序
// 98 验证：中序检查 prev < cur；230 第 k 小：中序计数到 k；
// 530 最小差：中序相邻作差取 min；538 累加树：反中序（右→根→左）累加
void inorder(TreeNode* root, TreeNode*& prev, bool& valid) {
    if (!root) return;
    inorder(root->left, prev, valid);
    if (prev && prev->val >= root->val) valid = false;  // 违反递增
    prev = root;
    inorder(root->right, prev, valid);
}
```

### 模板 6：树形 DP / 打家劫舍 III（后序返回状态对）

```cpp
// 337 打家劫舍 III：每个节点返回 {偷, 不偷} 两个状态，后序汇总
pair<int,int> dfs(TreeNode* root) {
    if (!root) return {0, 0};
    auto [ll, lr] = dfs(root->left);
    auto [rl, rr] = dfs(root->right);
    int rob     = root->val + lr + rr;          // 偷当前 → 左右都不能偷
    int notRob  = max(ll, lr) + max(rl, rr);    // 不偷当前 → 左右各取最优
    return {rob, notRob};
}
```

**要点：** 当一个节点的决策依赖子节点的「多种状态」时，让递归返回**结构体/数组/pair**，把状态一次性带上来，避免重复递归。同类：124 最大路径和、543 直径、968 监控二叉树、337。

## 三、模板选择决策树

```
是否需要逐层信息（层号/每层聚合/最短步数）？
├─ 是 → 模板 3 BFS 分层
└─ 否 → 是否是 BST？
        ├─ 是 → 优先模板 5 中序有序（或 BST 递归剪枝）
        └─ 否 → 信息是自顶向下还是自底向上？
                ├─ 自顶向下（父→子传参） → 模板 1 前序位置
                ├─ 自底向上（子→父汇总） → 模板 4 分解问题
                └─ 需要多状态决策         → 模板 6 树形 DP
是否要求 O(1) 空间 / 不能用递归？ → 模板 2 迭代 或 Morris
```

## 六、记忆口诀

> **递归三问**：返回什么？null 返回什么？左右拿到后怎么拼？
> **前序传下去，后序传上来；BFS 分层先取 size；BST 先想中序。**
> **一个返回值不够，就上 pair / 结构体（树形 DP）；要 O(1) 空间，就迭代 / Morris。**
