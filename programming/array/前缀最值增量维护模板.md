# 前缀最值增量维护模板

> 从 [3979. 最大有效数对和](./3979.maximum-valid-pair-sum.cpp) 抽象出的一类题：**遍历一个端点，另一个端点的候选范围随之单调变化，用一个变量/结构增量维护候选范围的最值**。
>
> 按「左侧候选范围如何变化」分三档，一档比一档强，模板可以逐档升级。

---

## 0. 通用问题模型

给定数组 `nums`，求：

$$
\max_{(i,j) \in S} \big( f(nums[i], i) \; op \; g(nums[j], j) \big)
$$

其中 `S` 是满足某种下标约束的数对集合，`op` 一般是 `+`、`-`、`max`。

**关键观察**：如果固定 `j`，那么 `i` 的可行域随 `j` 单调变化，`f` 部分的最值就可以增量维护，不用每次重扫。

按可行域的形状分三档：

| 档位 | 约束 | 左侧候选 | 维护工具 | 复杂度 |
|---|---|---|---|---|
| A | `j - i >= k`（或 `i < j`） | 前缀，只扩张 | 一个变量 | O(n) |
| B | 同上，再加 `key(i) == key(j)` | 按 key 分组的前缀 | 哈希表 / 桶数组 | O(n) |
| C | `\|i - j\| <= k` | 滑动窗口 | 单调队列 | O(n) |

## 1. 档位 A：前缀最值 + 单变量（3979 同款）

### 模板

```cpp
// 求 max{ f(nums[i]) op g(nums[j]) : j - i >= k }
int solve(vector<int>& nums, int k) {
    int ans = INIT;               // 依题意取 INT_MIN / INT_MAX / 0
    int best = INIT_LEFT;         // 左侧候选的当前最值（f 部分）
    for (int j = k; j < (int)nums.size(); j++) {
        // 1. 新进入左侧的候选：nums[j - k]
        best = max(best, f(nums[j - k], j - k));
        // 2. 用当前 j 更新答案
        ans  = max(ans, best op g(nums[j], j));
    }
    return ans;
}
```

### 三步口诀

1. **进**：`j` 右移一格，左侧多一个候选 `nums[j-k]`，用它更新 `best`
2. **算**：拿当前 `best` 和 `nums[j]` 组合更新答案
3. **不删**：左侧只扩张不收缩，所以不需要出队操作

### 典型变形

| 题目 | f | g | op | 约束 |
|---|---|---|---|---|
| 3979. 最大有效数对和 | `nums[i]` | `nums[j]` | `+` | `j - i >= k` |
| 2016. 增量元素之间的最大差值 | `-nums[i]` | `nums[j]` | `+` | `i < j` 且 `nums[j] > nums[i]` |
| 121. 买卖股票的最佳时机 | `-price[i]` | `price[j]` | `+` | `i < j` |
| 1014. 最佳观光组合 | `value[i] + i` | `value[j] - j` | `+` | `i < j` |
| 1749. 任意子数组和的绝对值的最大值 | 前缀和 `mn/mx` | 前缀和 `s` | `-` | `i <= j` |

### 3979 参考实现

```cpp
int maxValidPairSum(vector<int>& nums, int k) {
    int ans = 0, mx = 0;
    for (int j = k; j < (int)nums.size(); j++) {
        mx = max(mx, nums[j - k]);   // 进：把 nums[j-k] 加入左侧候选
        ans = max(ans, mx + nums[j]); // 算：用当前 mx 更新答案
    }
    return ans;
}
```

### 1014 参考实现（把 i、j 分离到 f、g 里）

```cpp
// value[i] + value[j] + i - j = (value[i] + i) + (value[j] - j)
int maxScoreSightseeingPair(vector<int>& value) {
    int ans = 0, mx = value[0] + 0;   // 左侧维护 value[i] + i 的最大值
    for (int j = 1; j < (int)value.size(); j++) {
        ans = max(ans, mx + value[j] - j);
        mx  = max(mx, value[j] + j);   // 注意：更新 mx 放在算完之后，避免 i == j
    }
    return ans;
}
```

> ⚠️ **顺序陷阱**：`best` 和 `ans` 的更新顺序要看约束。
> - `j - i >= k`（`k ≥ 1`）：先更新 `best` 再算 `ans`（此时 `nums[j-k]` 一定不是 `nums[j]`）
> - `i < j`（严格）：**先算 `ans` 再更新 `best`**，否则会把 `j` 自己算进 `best`

## 2. 档位 B：分组前缀最值

在 A 的基础上多一个约束 `key(i) == key(j)`。每个 key 独立维护一个前缀最值。

### 模板

```cpp
int solve(vector<int>& nums) {
    unordered_map<int, int> best;    // key -> 该 key 下 f(nums[i]) 的最值
    int ans = INIT;
    for (int j = 0; j < (int)nums.size(); j++) {
        int k = key(nums[j], j);
        if (best.count(k)) {
            ans = max(ans, best[k] op g(nums[j], j));
        }
        best[k] = max(best[k], f(nums[j], j));   // 当前元素作为后续的 i 加入
    }
    return ans;
}
```

### 典型题

| 题目 | key | f | g | op |
|---|---|---|---|---|
| 2342. 数位和相等数对的最大和 | 数位和 | `nums[i]` | `nums[j]` | `+` |
| 2815. 数组中的最大数对和 | 最大数位 | `nums[i]` | `nums[j]` | `+` |
| 1679. K 和数对的最大数目 | `k - x` | 计数 | 计数 | 计数 |
| 2364. 统计坏数对的数目 | `nums[i] - i` | 计数 | 计数 | `-` |

### 2342 参考实现

```cpp
int maximumSum(vector<int>& nums) {
    int ans = INT_MIN;
    unordered_map<int, int> best;   // 数位和 -> 该桶下的最大值
    for (int x : nums) {
        int k = digitSum(x);
        if (best.count(k)) ans = max(ans, best[k] + x);
        best[k] = max(best[k], x);
    }
    return ans == INT_MIN ? -1 : ans;
}
```

## 3. 档位 C：滑动窗口最值 + 单调队列

当约束变成 `|i - j| <= k`，左侧候选既会**扩张**（新元素加入）也会**收缩**（过期元素弹出），单变量不够用，需要单调队列。

### 模板

```cpp
int solve(vector<int>& nums, int k) {
    deque<int> dq;                     // 存下标，nums[dq] 单调递减
    int ans = INIT;
    for (int j = 0; j < (int)nums.size(); j++) {
        // 1. 弹：队首过期（下标 < j - k）
        while (!dq.empty() && dq.front() < j - k) dq.pop_front();
        // 2. 算：用队首（当前窗口最大值）更新答案
        if (!dq.empty()) ans = max(ans, nums[dq.front()] op g(nums[j], j));
        // 3. 进：从队尾踢掉所有 <= nums[j] 的，再入队
        while (!dq.empty() && nums[dq.back()] <= nums[j]) dq.pop_back();
        dq.push_back(j);
    }
    return ans;
}
```

### 三步口诀（弹-算-进）

1. **弹**：队首下标过期就 `pop_front`
2. **算**：此时队首就是窗口最大值，拿来更新答案
3. **进**：队尾所有比新元素小的都无用，`pop_back` 后入队

### 典型题

| 题目 | 场景 |
|---|---|
| 239. 滑动窗口最大值 | 模板本身 |
| 1696. 跳跃游戏 VI | DP + 单调队列优化：`dp[j] = nums[j] + max(dp[j-k..j-1])` |
| 1425. 带限制的子序列和 | 同上，允许负数 |
| 1499. 满足不等式的最大值 | `y_i - x_i + y_j + x_j` 且 `x_j - x_i <= k`，A + C 组合 |
| 862. 和至少为 K 的最短子数组 | 前缀和 + 单调队列 |
| 1438. 绝对差不超过限制的最长连续子数组 | 双单调队列同时维护 mx / mn |

### 1696 参考实现（**3979 的 DP + 单调队列版**）

```cpp
// dp[j] = nums[j] + max(dp[j-k], dp[j-k+1], ..., dp[j-1])
int maxResult(vector<int>& nums, int k) {
    int n = nums.size();
    vector<int> dp(n);
    deque<int> dq;                     // dp[dq] 单调递减
    dp[0] = nums[0];
    dq.push_back(0);
    for (int j = 1; j < n; j++) {
        while (!dq.empty() && dq.front() < j - k) dq.pop_front();  // 弹
        dp[j] = nums[j] + dp[dq.front()];                          // 算
        while (!dq.empty() && dp[dq.back()] <= dp[j]) dq.pop_back();// 进
        dq.push_back(j);
    }
    return dp[n - 1];
}
```

## 4. 快速选型对照表

看到题目里的约束长这样，直接对号入座：

| 约束形式 | 选档位 | 工具 |
|---|---|---|
| `j - i >= k`（差距至少 k） | A | 一个变量 |
| `i < j` 且带权重（`value[i]+i`） | A | 一个变量 |
| `key(i) == key(j)` | B | 哈希表 |
| `j - i <= k`（差距至多 k） | C | 单调队列 |
| `\|i - j\| ∈ [L, R]` | A + C | 单调队列 + 延迟入队 |

---

## 5. 常见坑

1. **best 更新时机**：约束是 `i < j`（严格）时必须「先算再更新」，`j - i >= k`（`k ≥ 1`）可以「先更新再算」。
2. **初始值**：如果 `nums[i]` 可能为负，`best` 初值取 `INT_MIN` 而不是 `0`；3979 因为题目保证 `nums[i] >= 0` 才可以取 0。
3. **单调队列的相等处理**：`pop_back` 用 `<=` 还是 `<` 看是否允许重复值；一般 `<=` 更简洁（保留新元素，下标更大更不容易过期）。
4. **DP 依赖顺序**：档位 C 用于 DP 优化时，`dp[j]` 要先算出来再入队，否则会影响后续状态。
5. **前缀最值 vs 后缀最值**：如果题目是"遍历 i 找右侧最值"，把模板反过来（从右往左扫）即可，本质完全对称。
