# 动态规划 C++ 模板（简单易记版）

## 核心思想：把大问题拆成重叠的小问题

动态规划五步曲（每题都按这个顺序想）：
1. **确定 dp 数组及下标含义**：`dp[i]` 到底代表什么？
2. **确定递推公式**：`dp[i]` 由哪些更小的状态推出来？
3. **初始化**：递推的起点，不能推导出来的值
4. **确定遍历顺序**：保证算 `dp[i]` 时依赖的状态已算好
5. **举例推导**：手动模拟一遍验证

> 股票系列的专题讲解见 [买卖股票问题.md](买卖股票问题.md)，通用模板看这一篇。

## 万能模板一：线性 DP（一维）

适用：爬楼梯、打家劫舍、最小花费爬楼梯……状态只和前几个位置有关。

```cpp
// 示例：198. 打家劫舍
int rob(vector<int>& nums) {
    int n = nums.size();
    vector<int> dp(n + 1);              // dp[i]: 前 i 间房能偷的最大金额
    dp[0] = 0, dp[1] = nums[0];         // 初始化起点
    for (int i = 2; i <= n; i++) {
        dp[i] = max(dp[i - 1],          // 不偷第 i 间
                    dp[i - 2] + nums[i - 1]); // 偷第 i 间
    }
    return dp[n];
}
```

**只需记住三句话：**
1. `dp[i]` 定义成"**到 i 为止**的最优解"（前缀式定义最好推）
2. 递推 = **不选 vs 选**，取 max（或 min）
3. 滚动优化：只依赖前两项时用两个变量代替数组

## 万能模板二：0-1 背包 与 完全背包（一维）

口诀：**0-1 背包容量倒序，完全背包容量正序**。

```cpp
// 0-1 背包：每件物品最多选一次
for (int i = 0; i < weight.size(); i++) {          // 遍历物品
    for (int j = bagWeight; j >= weight[i]; j--) { // 遍历容量【倒序】
        dp[j] = max(dp[j], dp[j - weight[i]] + value[i]);
    }
}

// 完全背包：每件物品可选无限次，改成【正序】即可
for (int i = 0; i < weight.size(); i++) {
    for (int j = weight[i]; j <= bagWeight; j++) { // 遍历容量【正序】
        dp[j] = max(dp[j], dp[j - weight[i]] + value[i]);
    }
}
```

> **为什么？** 倒序时 `dp[j - weight[i]]` 还是上一行（没选过物品 i）的值，保证每件只选一次；正序时它已被更新为本行，天然允许重复选。
> **求组合数**（494 目标和、518 零钱兑换 II）：外层物品内层容量，`dp[j] += dp[j - w]`。
> **求排列数**（377 组合总和 IV）：外层容量内层物品。

## 万能模板三：双序列 DP（二维）

适用：LCS、编辑距离、交错字符串……两个字符串各一个下标。

```cpp
// 示例：1143. 最长公共子序列（72. 编辑距离 同款骨架）
int longestCommonSubsequence(string s, string t) {
    int m = s.size(), n = t.size();
    vector<vector<int>> dp(m + 1, vector<int>(n + 1, 0)); // 前 i / 前 j
    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            if (s[i - 1] == t[j - 1])
                dp[i][j] = dp[i - 1][j - 1] + 1;          // 匹配：斜着继承
            else
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1]); // 不匹配：丢一个
        }
    }
    return dp[m][n];
}
```

**要点：** `dp` 多开一行一列表示空串，字符比较用 `s[i-1]` 对 `dp[i]`；"相等斜着继承，不等丢一个"。

## 万能模板四：状态机 DP（股票系列）

每天只有几种状态，每种状态一个 dp 变量，状态之间画转移箭头。

```cpp
// 示例：122. 买卖股票的最佳时机 II（可多次交易）
// hold: 今天结束时持有股票的最大利润   sold: 今天结束时不持有
int hold = -prices[0], sold = 0;
for (int i = 1; i < prices.size(); i++) {
    hold = max(hold, sold - prices[i]);   // 继续持有 / 今天买入
    sold = max(sold, hold + prices[i]);   // 继续空仓 / 今天卖出
}
return sold;
```

> 121 只能交易一次：`hold = max(-prices[i], ...)`，`sold = max(prices[i])`。
> 123/188 限制交易次数：给 hold/sold 加上"第 k 次"维度。

## 万能模板五：状态压缩 DP（bitmask）

适用：n 很小（一般 n ≤ 20）的"选/不选"组合问题——排列计数、集合划分、最小覆盖……
核心：**用一个二进制整数 `mask` 表示一个集合**，第 `i` 位为 1 表示第 `i` 个元素已被选/已覆盖。`dp[mask]` 就是"处在该集合状态时的答案"，状态总数 `1 << n`。

```cpp
// 骨架：从小到大枚举 mask，尝试加入一个还没选的元素 i
vector<int> dp(1 << n, /* 计数填 0 / 最值填 INF */);
dp[0] = /* 空集合的初始值 */;
for (int mask = 0; mask < (1 << n); ++mask) {
    if (/* dp[mask] 不可达 */) continue;
    for (int i = 0; i < n; ++i) {
        if (mask >> i & 1) continue;          // 第 i 个已选，跳过
        int nxt = mask | (1 << i);            // 选中第 i 个后的新状态
        dp[nxt] = /* 由 dp[mask] 转移：max/min/+= */;
    }
}
return dp[(1 << n) - 1];                       // 全集状态即答案
```

**三种常见形态（本目录各有一题示范）：**
1. **计数型** `dp[nxt] += dp[mask]`：526 优美的排列，`pos = popcount(mask)+1` 决定当前填第几个位置。
2. **划分型** 记录"当前未满组的和"：698 划分为 k 个相等子集，装满一组就对 `target` 取模归零。
3. **最小覆盖型** `dp[nxt] = min(dp[nxt], dp[mask]+1)`：1125 最小的必要团队，用 `pre/choose` 数组回溯还原方案。

> **常用技巧：** `__builtin_popcount(mask)` 数 1 的个数；`mask >> i & 1` 判第 i 位；`mask & (mask-1)` 去掉最低位的 1；`n` 较大时优先"集合维度小"的那一方做状压（如 1125 压技能而非压人）。

## 记忆口诀

> **一维看前缀，二维看斜角；0-1 倒序完全正序，组合物品外排列容量外；相等斜着走，不等丢一个。**
> **状压 n 小枚举 mask，`mask>>i&1` 判选没选，`mask|(1<<i)` 加一个；计数 `+=`、划分取模归零、覆盖 `min(+1)` 再回溯。**
> 写不出来就回到五步曲：dp 含义 → 递推 → 初始化 → 遍历顺序 → 手推验证。
