# 前缀和 + 哈希表 模板

> 从 [560. 和为 K 的子数组](./0560.合为k的子数组.cpp) 抽象出的一大类题：凡是问「**子数组 / 子串 / 路径的和**满足某种条件」的，都可以用「**前缀和把区间和拆成两个前缀之差 + 哈希表边扫边查**」把暴力的 O(n²) 降到 O(n)。
>
> 按「**哈希表里存什么、查询目标是什么**」分三种模式，模板逐模式套用即可。

---

## 0. 通用问题模型

记前缀和 `pre[i] = nums[0] + ... + nums[i-1]`（`pre[0] = 0` 为空前缀）。核心恒等式：

$$
\text{sum}(nums[j..i]) = pre[i+1] - pre[j]
$$

于是「找和满足条件的子数组」= 「对每个右端点 `i+1`，找有多少 / 哪个左端点 `j`，使 `pre[i+1] - pre[j]` 满足条件」。把条件移项成对 `pre[j]` 的要求，就能用哈希表在扫描时 O(1) 查询历史前缀。

**统一套路**：一边遍历、一边维护当前前缀 `s`，把「历史前缀的某种信息」存进哈希表，用当前 `s` 去查表。

| 查询目标 | 哈希表存什么 | 关键操作 | 模式 |
|---|---|---|---|
| 有多少个（计数） | 每个前缀值出现的**次数** | `ans += cnt[s-k]` | 一 |
| 最长 / 是否存在 | 每个前缀值**首次**出现的下标 | `ans = max(ans, i - first[s])` | 二 |
| 最短 | 每个前缀值**最近**出现的下标 | `ans = min(ans, i - last[s])` | 二 |

---

## 1. 模式一：计数型（哈希表存「出现次数」）

问「和为 k 的子数组有多少个」。对每个右端点，累加历史上 `pre[j] == s - k` 的个数。

### 模板（先查后插，显式初始化）

```cpp
int solve(vector<int>& nums, int k) {
    unordered_map<int, int> cnt{{0, 1}}; // 空前缀和 0 出现 1 次（处理从头开始的子数组）
    int ans = 0, s = 0;
    for (int x : nums) {
        s += x;                                  // 1. 更新当前前缀和
        ans += cnt.count(s - k) ? cnt[s - k] : 0; // 2. 先查：历史上有多少个 s-k
        cnt[s]++;                                // 3. 后插：把当前前缀和记入表
    }
    return ans;
}
```

### 三步口诀

1. **更**：`s += x` 更新当前前缀和
2. **查**：`ans += cnt[s-k]`（先查，避免把自己算进去）
3. **插**：`cnt[s]++`（后插）

> ⚠️ **顺序**：必须「先查后插」。若先插再查，当 `k == 0` 时会把当前位置自己当成合法左端点，多算一个空子数组。

### 等价写法（先插后更，省掉显式初始化）

把「插入当前前缀」放到「更新 `s`」之前，第一轮 `s == 0` 时自动完成 `cnt[0] = 1`：

```cpp
for (int x : nums) {
    cnt[s]++;   // 先记录「还没算上 x 的前缀和」，等价于自动初始化 cnt[0]=1
    s += x;
    ans += cnt.count(s - k) ? cnt[s - k] : 0;
}
```

> 根目录 [560.subarray-sum-equals-k.cpp](../../560.subarray-sum-equals-k.cpp) 与 [0930](./0930.和相同的二元子数组.cpp) 用的就是这种写法，两种完全等价。

### 值变换：把条件塞进前缀和

计数型的强大之处在于「**换个前缀和的定义**」就能套一堆题：

| 题目 | 前缀和定义 / 变换 | 查询目标 |
|---|---|---|
| [560. 和为 K 的子数组](./0560.合为k的子数组.cpp) | 原样前缀和 | `cnt[s-k]` |
| [930. 和相同的二元子数组](./0930.和相同的二元子数组.cpp) | 0/1 数组原样前缀和 | `cnt[s-goal]`（与 560 同构） |
| [974. 和可被 K 整除的子数组](./0974.和可被%20K%20整除的子数组.cpp) | 前缀和 **mod k** | `cnt[s%k]`（同余即整除） |
| [1524. 和为奇数的子数组数目](./1524.和为奇数的子数组数目.cpp) | 前缀和 **mod 2**（奇偶） | 当前偶→查奇数个数，反之亦然 |
| [1248. 统计「优美子数组」](../1248.统计「优美子数组」.cpp) | 把奇数记 1、偶数记 0 求前缀和 | `cnt[s-k]`（k 个奇数） |

> 974 的取模要小心 **C++ 负数取模**：`int r = (s % k + k) % k;` 把余数纠正到 `[0, k)`。

### 974 参考实现（mod 版计数）

```cpp
int subarraysDivByK(vector<int>& nums, int k) {
    unordered_map<int, int> cnt{{0, 1}}; // 余数 -> 次数
    int s = 0, ans = 0;
    for (int x : nums) {
        s += x;
        int r = (s % k + k) % k;  // 负数取模纠正
        ans += cnt[r];            // 同余的两个前缀，中间段能被 k 整除
        cnt[r]++;
    }
    return ans;
}
```

## 2. 模式二：最长 / 最短 / 存在型（哈希表存「下标」）

问「最长 / 最短 / 是否存在」满足条件的子数组。此时表里存下标，用下标之差算长度。

### 2.1 最长型（存**首次**下标）

```cpp
int solve(vector<int>& nums) {
    unordered_map<int, int> first{{0, -1}}; // 前缀值 -> 首次下标；空前缀下标设为 -1
    int ans = 0, s = 0;
    for (int i = 0; i < (int)nums.size(); i++) {
        s += transform(nums[i]);            // 视题目做值变换（0->-1 / mod / 异或…）
        if (first.count(s)) {
            ans = max(ans, i - first[s]);   // 相同前缀值 => 中间段满足条件，取最长
        } else {
            first[s] = i;                   // 只在首次出现时记录，才能保证最长
        }
    }
    return ans;
}
```

> **口诀**：`first[0] = -1` 打底 → 遇到见过的值就更新长度 → 没见过的才存下标（**绝不覆盖**）。

### 2.2 最短型（存**最近**下标）

与最长型相反：每次都覆盖下标（存最近位置），查询时取 `min`。见 [1590 参考实现](#1590-参考实现最短--取模)。

### 2.3 存在型（存首次下标 + 长度约束）

只判断是否存在，且常带「长度 ≥ 2」之类约束：查到后校验 `i - first[s] >= 2` 即可（见 523）。

### 题目对照

| 题目 | 前缀值定义 | 存/查 | 目标 |
|---|---|---|---|
| [525. 连续数组](./0525.连续数组.cpp) | 0 当 -1 的前缀和 | 首次下标 | 最长（和为 0） |
| [523. 连续的子数组和](./0523.连续的子数组和.cpp) | 前缀和 mod k | 首次下标 | 存在（长度≥2） |
| [1371. 每个元音包含偶数次的最长子字符串](./1371.每个元音包含偶数次的最长子字符串.cpp) | 5 元音奇偶**状态压缩** | 首次下标 | 最长（状态相同） |
| [1590. 使数组和能被 P 整除](./1590.使数组和能被p整除.cpp) | 前缀和 mod p | 最近下标 | 最短（删除段） |

### 1590 参考实现（最短 + 取模）

```cpp
int minSubarray(vector<int>& nums, int p) {
    long long total = 0;                     // 和可达 1e14，用 long long
    for (int x : nums) total += x;
    int target = total % p;
    if (target == 0) return 0;               // 已整除，删空段
    unordered_map<int, int> last{{0, -1}};   // 前缀余数 -> 最近下标
    long long s = 0;
    int n = nums.size(), ans = n;            // ans==n 是哨兵，表示只能删整个数组（非法）
    for (int i = 0; i < n; i++) {
        s += nums[i];
        int cur = s % p;
        int need = (cur - target) % p;       // 要找的历史前缀余数
        if (need < 0) need += p;             // 负数取模纠正
        if (last.count(need)) ans = min(ans, i - last[need]);
        last[cur] = i;                       // 每次都覆盖 => 存最近下标
    }
    return ans == n ? -1 : ans;
}
```

## 3. 模式三：树上 / 链表上的前缀和

前缀和不限于数组，**任何「从起点到当前点的累加路径」都能用**，只是哈希表要配合结构做维护。

### 3.1 树上：DFS + 回溯撤销（437）

树上前缀和 = 从根到当前节点的路径和。沿 DFS 下行时把 `curr` 记入哈希表，**回溯上行时必须撤销**（`prefix[curr]--`），否则会跨分支误统计。

见 [437. 路径总和 III](../tree/437.路径总和IIIcpp) 的第二个 `Solution`：

```cpp
unordered_map<long long, int> prefix{{0, 1}};
int dfs(TreeNode* root, long long curr, int targetSum) {
    if (!root) return 0;
    curr += root->val;
    int ret = prefix[curr - targetSum];  // 查：路径上有多少个前缀满足差为 target
    prefix[curr]++;                      // 插：当前前缀入表
    ret += dfs(root->left,  curr, targetSum);
    ret += dfs(root->right, curr, targetSum);
    prefix[curr]--;                      // 回溯：离开本节点，撤销，避免污染兄弟分支
    return ret;
}
```

> 注意用 `long long`：节点值累加可能溢出 `int`。

### 3.2 链表上：两趟 + 存「最后节点」（1171）

见 [1171. 从链表中删去总和值为零的连续节点](./1171.从链表中删去总和值为零的连续节点.cpp)。删除和为 0 的连续段 <=> 首尾前缀和相等。技巧是**存每个前缀和最后出现的节点**，两趟扫描：

```cpp
ListNode dummy(0); dummy.next = head;
unordered_map<int, ListNode*> last;
// 第一趟：记录每个前缀和的最后节点（后写覆盖前写）
for (ListNode* p = &dummy; p; p = p->next) { s += p->val; last[s] = p; }
// 第二趟：让每个节点直接跳到「相同前缀和的最后节点」的后继，一步跨过零和段
for (ListNode* p = &dummy; p; p = p->next) { s += p->val; p->next = last[s]->next; }
return dummy.next;
```

> 存「最后」而非「首次」，才能一次性跨过所有嵌套 / 相邻的零和段，不用真的反复删。

## 4. 值变换技巧对照表

很多题第一眼不像前缀和，**做一次值变换就归位**：

| 原始条件 | 变换 | 归位到 |
|---|---|---|
| 0 和 1 数量相等 | `0 → -1` | 和为 0（525） |
| 和能被 k 整除 | 前缀和 `mod k` | 同余（974 / 523 / 1590） |
| 和为奇数 | 前缀和 `mod 2` | 奇偶配对（1524） |
| 恰含 k 个奇数 | 奇数记 1、偶数记 0 | 和为 k（1248） |
| 每个元音出现偶数次 | 5 位**异或状态压缩** | 前缀状态相同（1371） |

## 6. 常见坑

1. **初始化哨兵**：计数型 `cnt[0] = 1`、下标型 `first[0] = -1`，用来处理「从下标 0 开始」的子数组，漏了会少算。
2. **先查后插**：计数型必须 `ans += cnt[s-k]` 之后再 `cnt[s]++`；反了会在 `k == 0` 时多算空子数组。（模式一的等价写法是靠「先插未更新的前缀」规避，本质一致。）
3. **最长存首次、最短存最近**：最长型只在**首次**出现时写下标（`else` 分支），最短型**每次都覆盖**。搞反结果就错。
4. **C++ 负数取模**：`(x % k + k) % k` 才能落到 `[0, k)`；974 / 1590 必须处理，523 因数据非负可省。
5. **`operator[]` 会插入**：查询用 `count()` / `contains()` 判存在，别直接 `cnt[key]`，否则不存在的 key 会被插入、白白撑大表。
6. **溢出**：元素大 / 数组长时前缀和用 `long long`（1590、437 尤其注意）。
7. **树上要回溯撤销**：437 离开节点时 `prefix[curr]--`，否则不同分支互相污染。
