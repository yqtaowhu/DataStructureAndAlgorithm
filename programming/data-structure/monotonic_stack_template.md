# 单调栈 / 单调队列 C++ 模板（简单易记版）

## 核心思想：维护"有秩序"的栈

单调栈解决一类经典问题：**对每个元素，找它左边/右边第一个比它大（小）的元素**。
- 栈内元素从栈底到栈顶**保持单调**（递减或递增）
- 新元素入栈前，把**破坏单调性的元素全部弹出**——弹出的瞬间，两者的关系就确定了
- 每个元素最多入栈、出栈各一次，整体 `O(n)`

> 单调队列（滑动窗口最大值）是它的孪生兄弟，见模板三。
> 数组模拟栈/队列的写法见 [数组模拟栈.md](数组模拟栈.md)。

## 万能模板一：单调栈（下一个更大元素）

```cpp
// 示例：496/503 下一个更大元素（739 每日温度 同款）
// 求每个元素右边第一个比它大的元素下标，没有则 -1
vector<int> nextGreater(vector<int>& nums) {
    int n = nums.size();
    vector<int> ans(n, -1);
    stack<int> st;                       // 存下标，栈内对应的值单调递减
    for (int i = 0; i < n; i++) {
        while (!st.empty() && nums[i] > nums[st.top()]) {
            ans[st.top()] = i;           // i 就是 top 的"下一个更大"
            st.pop();
        }
        st.push(i);
    }
    return ans;
}
```

**只需记住三句话：**
1. 栈里存**下标**（方便填答案）
2. 新元素把栈顶"压制"时，栈顶的答案就是当前下标
3. 找"下一个更大"→ 维护**递减**栈；找"下一个更小"→ 维护**递增**栈（比较符号取反）

## 变体：环形数组（503）

技巧：**遍历 2n 次，下标取模**，逻辑完全不变。

```cpp
for (int i = 0; i < 2 * n; i++) {
    int x = nums[i % n];
    while (!st.empty() && x > nums[st.top()]) {
        ans[st.top()] = x; st.pop();
    }
    if (i < n) st.push(i);   // 只在第一圈入栈，避免重复
}
```

## 万能模板二：接雨水 / 柱状图（横向贡献）

```cpp
// 示例：42. 接雨水 —— 一根柱子上方能接的水由左右最高柱决定
// 单调递减栈：弹出栈顶时，它左右第一个更高的柱子就是栈顶之后/之前的元素
int trap(vector<int>& height) {
    stack<int> st; int water = 0;
    for (int i = 0; i < height.size(); i++) {
        while (!st.empty() && height[i] > height[st.top()]) {
            int bottom = height[st.top()]; st.pop();     // 凹槽底
            if (st.empty()) break;                        // 左边没有墙，接不住
            int w = i - st.top() - 1;                     // 宽
            int h = min(height[i], height[st.top()]) - bottom; // 高
            water += w * h;
        }
        st.push(i);
    }
    return water;
}

// 84. 柱状图中最大矩形：单调递增栈，弹出时以它为高的矩形宽度 = i - st.top() - 1
// （前后各加一个哨兵 0，避免栈剩到最后）
```

> 85. 最大矩形 = 84 逐行叠加前缀高度。

## 万能模板三：单调队列（滑动窗口最大值）

队列存下标，**队头永远是当前窗口最大值**。

```cpp
// 示例：239. 滑动窗口最大值
vector<int> maxSlidingWindow(vector<int>& nums, int k) {
    deque<int> dq;                       // 存下标，对应的值从队头到队尾递减
    vector<int> ans;
    for (int i = 0; i < nums.size(); i++) {
        // 1. 入：队尾比它小的全弹出（它们已不可能成为最大值）
        while (!dq.empty() && nums[dq.back()] <= nums[i]) dq.pop_back();
        dq.push_back(i);
        // 2. 出：队头滑出窗口
        if (dq.front() <= i - k) dq.pop_front();
        // 3. 更新：窗口形成后，队头即最大值
        if (i >= k - 1) ans.push_back(nums[dq.front()]);
    }
    return ans;
}
```

**要点：** 每个"潜力不足"的元素在被压入前就被淘汰，所以队列长度虽可能小于窗口，但队头必是最大值——均摊 `O(n)`。

## 改一处，解决一类问题

| 问题 | 改哪里 |
|------|--------|
| 每日温度（739） | ans[top] = i - top（存天数差） |
| 下一个更大元素 II（503） | 环形：遍历 2n，下标取模 |
| 接雨水（42） | 弹栈时算凹槽 `w * h` |
| 柱状图最大矩形（84） | 递增栈 + 哨兵，宽 = i - top - 1 |
| 最大矩形（85） | 每行调一次 84 |
| 去除重复字母/移除 K 位数字最小（316/402） | 递增栈 + 贪心弹栈 + 字符计数控制 |
| 滑动窗口最大值（239） | 单调队列标准模板 |
