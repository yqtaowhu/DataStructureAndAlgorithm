# 前缀后缀分解模板

> 从 [3904. 最小稳定下标 II](./3904.smallest-stable-index-ii.cpp) 抽象出的一类题：**固定中间位置，需要快速查询其左侧和右侧的某种极值信息**。
>
> 核心思想：通过预处理将 O(n²) 的暴力枚举优化到 O(n)，用空间换时间。

---

## 0. 通用问题模型

给定数组 `nums`，求：

$$\max_{i} \big( f(\text{left}[i]) \; op \; g(\text{right}[i]) \big)$$

其中 `left[i]` 表示位置 i 左侧的信息，`right[i]` 表示位置 i 右侧的信息。

**关键观察**：如果直接对每个位置都重新扫描左右两侧，复杂度为 O(n²)。但可以通过**前后缀预处理**将每次查询优化到 O(1)。

按「需要维护的信息类型」分三类：

| 类型 | 需要信息 | 预处理方式 | 复杂度 |
|---|---|---|---|
| A | 前缀/后缀最值 | 单个数组 | O(n) |
| B | 前缀/后缀 LIS/LDS | DP + 反转 | O(n log n) |
| C | 前缀/后缀状态压缩 | 位运算/哈希 | O(n) |

## 1. 类型 A：前缀/后缀最值（3904 同款）

### 模板

```cpp
// 场景：遍历 j，需要知道 j 左侧的最大值和右侧的最小值
int solve(vector<int>& nums, int k) {
    int n = nums.size();
    
    // 1. 预处理后缀信息
    vector<int> suf_min(n);
    suf_min[n - 1] = nums[n - 1];
    for (int i = n - 2; i >= 0; i--) {
        suf_min[i] = min(suf_min[i + 1], nums[i]);
    }
    
    // 2. 扫描时维护前缀信息
    int pre_max = nums[0];
    int ans = -1;
    for (int j = 0; j < n; j++) {
        // 检查条件
        if (pre_max - suf_min[j] <= k) {
            return j;  // 找到第一个满足条件的
        }
        
        // 更新前缀最大值
        pre_max = max(pre_max, nums[j]);
    }
    return -1;
}
```

### 三步口诀

1. **后处理**：从右往左扫，计算后缀数组 `suf[i] = op(suf[i+1], nums[i])`
2. **前维护**：从左往右扫，用单变量维护前缀信息
3. **即时算**：在扫描过程中即时检查条件并更新答案

### 典型变形

| 题目 | 左侧信息 | 右侧信息 | 条件 |
|---|---|---|---|
| 3904. 最小稳定下标 II | 前缀最大值 | 后缀最小值 | `pre_max - suf_min <= k` |
| 2909. 元素和最小的山形三元组 II | 前缀最小值 | 后缀最小值 | `pre < mid && suf < mid` |
| 0042. 接雨水 | 前缀最大值 | 后缀最大值 | `min(leftMax, rightMax) - height` |
| 0738. 单调递增的数字 | 前缀信息 | 后缀填充 | 贪心调整 |

### 3904 参考实现

```cpp
int firstStableIndex(vector<int>& nums, int k) {
    int n = nums.size();
    vector<int> suf_min(n);
    suf_min[n - 1] = nums[n - 1];
    for (int i = n - 2; i >= 0; i--) {
        suf_min[i] = min(suf_min[i + 1], nums[i]);
    }

    int pre_max = 0;
    for (int i = 0; i < n; i++) {
        pre_max = max(pre_max, nums[i]);
        if (pre_max - suf_min[i] <= k) {
            return i;
        }
    }
    return -1;
}
```

### 2909 参考实现（山形三元组）

```cpp
int minimumSum(vector<int>& nums) {
    int n = nums.size();
    vector<int> suf(n, INT_MAX);
    suf[n-1] = nums[n-1];
    for (int i = n - 2; i >= 0; i--) {
        suf[i] = min(suf[i + 1], nums[i + 1]);
    }
    
    int ans = INT_MAX;
    int pre = nums[0];
    for(int j=1; j < n-1; j++) {
        if(pre < nums[j] && nums[j] > suf[j]) {
            ans = min(ans, pre + nums[j] + suf[j]);
        }
        pre = min(pre, nums[j]);
    }
    return ans == INT_MAX ? -1 : ans;
}
```

### 0042 参考实现（接雨水 - 双指针优化版）

```cpp
int trap(vector<int>& height) {
    int ans = 0;
    int left = 0, right = height.size() - 1;
    int leftMax = 0, rightMax = 0;
    
    while (left < right) {
        leftMax = max(leftMax, height[left]);
        rightMax = max(rightMax, height[right]);
        
        if (height[left] < height[right]) {
            ans += leftMax - height[left];
            ++left;
        } else {
            ans += rightMax - height[right];
            --right;
        }
    }
    return ans;
}
```

## 2. 类型 B：前缀/后缀 LIS/LDS（山形数组）

### 模板

```cpp
// 场景：需要知道以每个位置结尾的最长上升子序列长度
vector<int> get_lis_array(vector<int>& nums) {
    int n = nums.size();
    vector<int> dp(n, 1), g;
    for (int i = 0; i < n; ++i) {
        auto it = lower_bound(g.begin(), g.end(), nums[i]);
        if(it == g.end()) {
            g.push_back(nums[i]);
            dp[i] = g.size();
        } else {
            *it = nums[i];
            dp[i] = it - g.begin() + 1;
        }
    }
    return dp;
}

// 组合前缀和后缀信息
int solve(vector<int>& nums) {
    // 1. 计算前缀 LIS
    vector<int> pre = get_lis_array(nums);
    
    // 2. 反转数组，计算后缀 LIS（即原数组的后缀 LDS）
    vector<int> reversed_nums(nums.rbegin(), nums.rend());
    vector<int> suf = get_lis_array(reversed_nums);
    reverse(suf.begin(), suf.end());
    
    // 3. 组合答案
    int ans = 0;
    for(int i=0; i<nums.size(); i++) {
        if(pre[i] > 1 && suf[i] > 1) {
            ans = max(pre[i] + suf[i] - 1, ans);
        }
    }
    return ans;
}
```

### 三步口诀

1. **前 LIS**：从左往右扫，计算每个位置结尾的最长上升子序列
2. **后 LDS**：反转数组再扫一次，得到每个位置开头的最长下降子序列
3. **合并减一**：山峰长度 = 前 LIS + 后 LDS - 1（峰值被算了两次）

### 典型题

| 题目 | 左侧要求 | 右侧要求 | 目标 |
|---|---|---|---|
| 1671. 得到山形数组的最少删除次数 | 前缀 LIS | 后缀 LDS | 最大化 `pre[i] + suf[i] - 1` |
| 84. 柱状图中最大的矩形 | 左侧小于 | 右侧小于 | 最大宽度 × 高度 |
| 85. 最大矩形 | 同上 | 同上 | 二维扩展 |

### 1671 参考实现

```cpp
int minimumMountainRemovals(vector<int>& nums) {
    vector<int> pre = get_lis_array(nums);
    vector<int> reversed_nums(nums.rbegin(), nums.rend());
    vector<int> suf = get_lis_array(reversed_nums);
    reverse(suf.begin(), suf.end());
    
    int ans = 0;
    for(int i=0; i<nums.size(); i++) {
        if(pre[i] > 1 && suf[i] > 1) {
            ans = max(pre[i] + suf[i] - 1, ans);
        }
    }
    return nums.size() - ans;
}
```

### 84 参考实现（单调栈优化）

```cpp
int largestRectangleArea(vector<int>& heights) {
    int m = heights.size(), res = 0;
    stack<int> st;
    st.push(-1);
    
    for(int i=0; i<m; i++) {
        while(st.top()!= -1 && heights[st.top()] >= heights[i]) {
            int index = st.top();
            st.pop();
            res = max(res, heights[index] * (i-st.top()-1)); 
        }
        st.push(i);
    }
    
    while(st.top() != -1) {
        int index = st.top();
        st.pop();
        res = max(res, heights[index] * (m - st.top() -1));
    }
    return res;
}
```

## 3. 类型 C：前缀/后缀状态压缩（字符串）

### 模板

```cpp
// 场景：需要知道某个范围内出现了哪些字符
int solve(string s) {
    int n = s.size();
    
    // 1. 前缀状态压缩（每一位代表一个字符是否出现）
    vector<int> pre(n);
    for (int i = 0; i < n; ++i) {
        pre[i] = (i ? pre[i-1] : 0) | (1 << (s[i] - 'a'));
    }
    
    // 2. 后缀状态压缩
    vector<int> suf(n);
    for (int i = n - 1; i >= 0; --i) {
        suf[i] = (i != n - 1 ? suf[i+1] : 0) | (1 << (s[i] - 'a'));
    }
    
    // 3. 组合答案
    int res = 0;
    for (int i = 1; i < n - 1; ++i) {
        // 中间字符 s[i]，左右两侧共有多少种不同字符
        int common = pre[i-1] & suf[i+1];
        res += __builtin_popcount(common);
    }
    return res;
}
```

### 三步口诀

1. **前缀压缩**：用位掩码记录前缀中出现的所有字符
2. **后缀压缩**：同样用位掩码记录后缀中出现的所有字符
3. **位运算合并**：通过 AND/OR/POPCOUNT 等位运算统计信息

### 典型题

| 题目 | 状态定义 | 合并方式 |
|---|---|---|
| 1930. 长度为 3 的不同回文子序列 | 字符出现集合 | `pre & suf` + `popcount` |
| 1371. 每个元音包含偶数次的最长子字符串 | 奇偶状态 | XOR 前缀和 |
| 0525. 连续数组 | 0/1 计数差 | 哈希表存首次出现位置 |

### 1930 参考实现

```cpp
int countPalindromicSubsequence(string s) {
    int n = s.size();
    vector<int> pre(n), suf(n);
    
    // 前缀状态
    for (int i = 0; i < n; ++i) {
        pre[i] = (i ? pre[i-1] : 0) | (1 << (s[i] - 'a'));
    }
    
    // 后缀状态
    for (int i = n - 1; i >= 0; --i) {
        suf[i] = (i != n - 1 ? suf[i+1] : 0) | (1 << (s[i] - 'a'));
    }
    
    // 统计答案
    int res = 0;
    for (int i = 1; i < n - 1; ++i) {
        res += __builtin_popcount(pre[i-1] & suf[i+1]);
    }
    return res;
}
```

## 4. 特殊情况：单调栈解法

某些前缀后缀问题可以用单调栈进一步优化，特别是涉及「下一个更大/更小元素」的场景。

### 模板

```cpp
// 找每个元素左边第一个大于它的位置
vector<int> find_left_greater(vector<int>& nums) {
    int n = nums.size();
    vector<int> left(n, -1);
    stack<int> st;
    
    for (int i = 0; i < n; i++) {
        while (!st.empty() && nums[st.top()] <= nums[i]) {
            st.pop();
        }
        if (!st.empty()) left[i] = st.top();
        st.push(i);
    }
    return left;
}

// 找每个元素右边第一个大于它的位置
vector<int> find_right_greater(vector<int>& nums) {
    int n = nums.size();
    vector<int> right(n, n);
    stack<int> st;
    
    for (int i = n - 1; i >= 0; i--) {
        while (!st.empty() && nums[st.top()] <= nums[i]) {
            st.pop();
        }
        if (!st.empty()) right[i] = st.top();
        st.push(i);
    }
    return right;
}
```

### 典型应用

| 题目 | 左侧查找 | 右侧查找 | 计算 |
|---|---|---|---|
| 84. 柱状图中最大的矩形 | 左侧小于 | 右侧小于 | `(right[i] - left[i] - 1) * height[i]` |
| 738. 单调递增的数字 | 下降位 | 全填 9 | 贪心调整 |

## 6. 常见坑

1. **边界处理**：
   - 后缀数组初始化：`suf[n-1] = nums[n-1]`
   - 循环起点：`for (int i = n - 2; i >= 0; i--)`
   - 空数组判断：提前返回

2. **索引范围**：
   - 山形三元组：`j` 的范围是 `[1, n-2]`，不能取端点
   - 回文子序列：中间字符范围 `[1, n-2]`

3. **初始化值**：
   - 最小值问题：初始化为 `INT_MAX`
   - 最大值问题：初始化为 `INT_MIN` 或 `0`（根据题意）
   - 后缀最小值：可能要用 `INT_MAX` 作为哨兵

4. **重复计算**：
   - 山形数组合并时要 `-1`（峰值被算了两次）
   - 注意不要重复统计

5. **单调栈顺序**：
   - 从左往右扫 vs 从右往左扫
   - 栈中存的是索引还是值
   - 弹出条件是 `<` 还是 `<=`

## 8. 与其他模板的关系

### 与前缀最值增量维护模板的区别

| 维度 | 前缀后缀分解 | 前缀最值增量维护 |
|---|---|---|
| 数据流方向 | 双向（先处理后算） | 单向（边算边维护） |
| 空间复杂度 | O(n) 额外数组 | O(1) 单变量 |
| 适用场景 | 需要同时访问左右两侧 | 只需维护一侧候选 |
| 经典题 | 3904, 2909, 0042 | 3979, 1014, 121 |

### 与滑动窗口的区别

| 维度 | 前缀后缀分解 | 滑动窗口 |
|---|---|---|
| 窗口大小 | 动态变化（0 到当前位置） | 固定大小 k |
| 是否需要删除 | 否 | 是（过期元素） |
| 工具 | 前缀数组 | 单调队列 |
| 经典题 | 3904, 2909 | 239, 1696 |

1. **基础题**：直接套用前后缀最值模板
