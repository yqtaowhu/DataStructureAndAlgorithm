# 滑动窗口 C++ 模板（简单易记版）

## 核心思想：右指针扩张，左指针收缩

滑动窗口是同向双指针的特例：维护一个**满足条件的连续区间** `[left, right]`。
- **右指针**负责扩张（探索新元素），永远只前进
- **左指针**负责收缩（维持窗口性质），也永远只前进
- 两个指针各走 `n` 步 ⇒ 总操作数 `2n`，复杂度 `O(n)` 而不是暴力的 `O(n^2)`
- **均摊分析**：`while` 看着像嵌套循环，但 `left` 全程只增不减，累计最多 `n` 次

### 能不能用滑动窗口？看三条

1. 求的是**连续**子数组 / 子串（不连续的用 DP、哈希、回溯）
2. 窗口有**单调性**：右移扩大窗口时，某个量单调变化（和变大、种类变多、重复变多……），
   从而"一旦不合法，左边收缩一定能重新合法"
3. 问法是四类之一：**定长统计 / 求最长 / 求最短 / 求个数**

> **反例（单调性被破坏）**：数组含负数时窗口和不再单调 ⇒ 862 必须换「前缀和 + 单调队列」；
> 求"和为 k 的子数组个数"（560，含负数）⇒ 前缀和 + 哈希表。

## 万能模板一：不定长窗口 · 求最长

关键口诀：**右移找可行，左移保合法，结束再更新答案**。

```cpp
// 示例：1004. 最大连续 1 的个数 III（把 0 翻转成 1 最多 k 个）
int longestOnes(vector<int>& nums, int k) {
    int left = 0, cnt0 = 0, ans = 0;
    for (int right = 0; right < (int)nums.size(); right++) {
        cnt0 += nums[right] == 0;              // 1. 入：right 元素进窗口
        while (cnt0 > k) {                     // 2. 出：窗口不合法，左端收缩
            cnt0 -= nums[left++] == 0;
        }
        ans = max(ans, right - left + 1);      // 3. 更新：此时窗口一定合法
    }
    return ans;
}
```

**只需记住三句话：**
1. `right` 每轮扩张一次（入窗口）
2. `while` 收缩到窗口重新合法（出窗口）
3. 收缩完的窗口**一定合法**，直接更新答案

**两个提速技巧：**
- 计数容器优先用**数组/`vector`** 代替 `unordered_map`（值域已知时），再用一个 `kinds` 变量
  维护"种类数"，避免每次算 `cnt.size()`（见 [904](0904.水果成篮.cpp)、[159](0159.至多包含两个不同字符的最长子串.cpp)、[340](0340.至多包含k个不同字符的最长子串.cpp)、[992](0992.k个不同整数的子数组.cpp)）
- 424 的 `maxCnt` **只增不减**：答案只会更大，`maxCnt` 变小时窗口本来也变不长，无需回退

## 万能模板二：不定长窗口 · 求最短

与求最长唯一的区别：**在收缩的过程中更新答案**（每个合法窗口都要量一遍最短的）。

```cpp
// 示例：209. 长度最小的子数组
int minSubArrayLen(int target, vector<int>& nums) {
    int left = 0, sum = 0, ans = INT_MAX;
    for (int right = 0; right < (int)nums.size(); right++) {
        sum += nums[right];                     // 入
        while (sum >= target) {                 // 满足条件就缩
            ans = min(ans, right - left + 1);   // 收缩前更新：这个窗口是合法的
            sum -= nums[left++];                // 出
        }
    }
    return ans == INT_MAX ? 0 : ans;
}
```

> **最长 vs 最短记忆法：** 求最长 → 出完再更新；求最短 → 边出边更新。

覆盖型（76 最小覆盖子串）的标准写法：`need` 记需求、`window` 记窗口内计数、
`valid` 记"已满足的字符种类数"，`valid == need.size()` 时收缩并记录答案。
438/567/3697/3698 都是这一套的变体。

- **`valid` 只在"刚好凑够"时变动**：入窗后 `window[c] == need[c]` 才 `valid++`，出窗前
  `window[d] == need[d]` 才 `valid--`（超量时不动），否则同一字符会被重复计数
- 字符集为 ASCII 时把 `need`/`window` 换成 `int[128]`、`need.size()` 换成 `kinds` 变量，
  空间降到 `O(1)`（见 [76](0076.最小覆盖子串.cpp)，文件里同时保留了通用哈希版）

## 万能模板三：定长窗口（长度恰好为 k）

三步走：**入 → 更新 → 出**，无 `while`，代码更短。

```cpp
// 示例：643. 子数组最大平均数 I / 1456. 定长子串中元音的最大数目
double findMaxAverage(vector<int>& nums, int k) {
    long long sum = 0, ans = LLONG_MIN;
    for (int right = 0; right < (int)nums.size(); right++) {
        sum += nums[right];                     // 1. 入：新元素进窗口
        if (right < k - 1) continue;            // 窗口未满，先不统计
        ans = max(ans, sum);                    // 2. 更新：窗口长度恰好为 k
        sum -= nums[right - k + 1];             // 3. 出：滑出左端元素
    }
    return (double)ans / k;
}
```

- `if (right < k - 1) continue;` 是**定长模板的灵魂**：它保证统计时窗口长度恰好为 k
- 统计型定长窗口（438/567）：比较窗口内字符计数数组是否相等（或 `valid == need.size()`）即可
- 环形数组（2134）：让 `right` 走 `[0, 2n)`，取值一律 `right % n`，等价于把数组拼两遍

## 万能模板四：计数型（求合法子数组 / 子串的个数）

求最长时"每轮记一次最大值"，求个数时改成"每轮累加以 `right` 结尾的合法窗口数"，
**不重不漏**（每个子数组都有唯一的右端点）。两个方向要分清：

```cpp
// 方向 A：窗口越短越容易合法（713 乘积 < k）⇒ 每轮 += right - left + 1
int numSubarrayProductLessThanK(vector<int>& nums, int k) {
    if (k <= 1) return 0;                       // 坑：否则 while 里 left 会越过 right
    int left = 0, ans = 0;
    long long prod = 1;
    for (int right = 0; right < (int)nums.size(); right++) {
        prod *= nums[right];                    // 入
        while (prod >= k) prod /= nums[left++]; // 出：缩到合法
        ans += right - left + 1;                // 以 right 结尾、起点任取 [left, right]
    }
    return ans;
}

// 方向 B：窗口越长越容易合法（1358 含 a/b/c 的子串数）⇒ 收缩到刚好不合法，每轮 += left
int numberOfSubstrings(string s) {
    int cnt[3] = {0}, left = 0, ans = 0;
    for (int right = 0; right < (int)s.size(); right++) {
        cnt[s[right] - 'a']++;
        while (cnt[0] && cnt[1] && cnt[2]) cnt[s[left++] - 'a']--;  // 出：缩到刚好不合法
        ans += left;                            // 起点取 0..left-1 全都合法
    }
    return ans;
}
```

> **判断走 A 还是 B：** 问自己"把窗口拉长，条件更容易满足还是更难满足？"
> 更难（乘积变大、0 变多）走 A；更容易（种类集齐、和变大）走 B。

## 万能模板五：恰好型 = 至多(k) − 至多(k−1)

"恰好 k 个不同整数 / 恰好 k 个奇数"这类**恰好型**没法直接滑窗
（多一个少一个都要缩，单调性断了），标准解法是拆成两个**至多型**相减：

```cpp
int atMostK(vector<int>& nums, int k) {         // 就是模板四方向 A
    if (k < 0) return 0;
    int n = nums.size(), left = 0, kinds = 0, res = 0;
    vector<int> cnt(n + 1, 0);                  // 1 <= nums[i] <= n
    for (int right = 0; right < n; right++) {
        if (cnt[nums[right]]++ == 0) kinds++;   // 入
        while (kinds > k)                       // 出
            if (--cnt[nums[left++]] == 0) kinds--;
        res += right - left + 1;                // 更新
    }
    return res;
}

int subarraysWithKDistinct(vector<int>& nums, int k) {
    return atMostK(nums, k) - atMostK(nums, k - 1);   // 恰好 = 至多 − 至多
}
```

同族：992、930（和相同的二元子数组）、1248（统计「优美子数组」，把奇数看成 1）。
也可以用"窗口内保留最左/最右重复位置"的写法，但相减法最好记。

## 万能模板六：单调队列窗口（窗口内要最值 / 数组含负数）

窗口内需要 `max`/`min` 时，重算是 `O(k)`，用**单调队列**降到均摊 `O(1)`：
队列存**下标**，队首永远是窗口内的最值；入队前把"永远不可能翻身"的队尾弹掉，
队首下标过期（滑出窗口）时弹出。

```cpp
// 示例：239. 滑动窗口最大值
vector<int> maxSlidingWindow(vector<int>& nums, int k) {
    deque<int> dq;                              // 下标队列，nums[dq] 递减，队首最大
    vector<int> ans;
    for (int right = 0; right < (int)nums.size(); right++) {
        while (!dq.empty() && nums[dq.back()] <= nums[right]) dq.pop_back();  // 入：弹队尾
        dq.push_back(right);
        if (dq.front() <= right - k) dq.pop_front();                          // 出：下标过期
        if (right >= k - 1) ans.push_back(nums[dq.front()]);                  // 更新
    }
    return ans;
}
```

- [1438](1438.绝对差不超过限制的最长连续子数组.cpp)：开**两个**队列（递减存 max、递增存 min），
  不合法条件是 `nums[mx.front()] - nums[mn.front()] > limit`
- [862](0862.和至少为k的最短子数组.cpp)：含负数 ⇒ 对**前缀和**建递增队列，
  `pre[i] - pre[dq.front()] >= k` 时记录答案并弹队首（`i` 再右移只会更长，队首已无价值）

## 万能模板七：逆向转化（两端取 / 环形）

"只能从两端取"这类题，正面很难滑窗，**反过来算中间那段连续子数组**就变成标准模板：

| 题 | 转化 |
|----|------|
| 1423 可获得的最大点数 | 两端取 k 张最大 ⇔ 中间连续 `n-k` 张**和最小**（定长窗口）|
| 1658 将 x 减到 0 的最小操作数 | 两端取走的和 = x ⇔ 中间连续子数组和 = `total-x` 且**最长**（模板一）|
| 2134 最少交换次数组合所有 1 | 1 的总个数 = 定长窗口长度，数窗口内 0 的最少个数（环形走 2n）|

```cpp
// 示例：1423 的骨架
long long total = 0, sum = 0, minSum = LLONG_MAX;
int win = n - k;
for (int right = 0; right < n; right++) {
    sum += cardPoints[right];                   // 1. 入
    if (right < win - 1) continue;              // 窗口未满
    minSum = min(minSum, sum);                  // 2. 更新
    sum -= cardPoints[right - win + 1];         // 3. 出
}
return total - minSum;                          // 两端最大 = 总和 − 中间最小
```

## 六个高频坑

1. **更新时机**：求最长在 `while` 之后更新，求最短在 `while` 之内更新，搞反就错
2. **窗口未满**：定长模板漏掉 `if (right < k - 1) continue;` 会把短窗口也算进去
3. **整型溢出**：和/乘积/前缀和一律 `long long`（862 前缀和可达 1e10，2461 元素可为负）
4. **初值**：求最短用 `INT_MAX` 并在最后判空返回 0；求最长且元素可为负时用 `LLONG_MIN`（2461）
5. **死循环**：713 中 `k <= 1` 时任何窗口都不合法，必须先 `return 0`，否则 `left` 会越过 `right`
6. **细节修正**：1493 要求"必须删掉一个元素"，答案是 `right - left`（窗口长度减 1）而不是 `+1`

## 记忆口诀

> **右进左出不离谱，求长出完再更新，求短边缩边记录，定长三步入更出。**
> **计数就加窗口数，恰好拆成至多减，最值配单调队列，两端环形反过来。**
> 判断窗口合法性只看「入」的那个元素带来的影响，别全量重算。
