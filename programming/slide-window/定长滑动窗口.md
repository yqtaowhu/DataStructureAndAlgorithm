# 定长滑动窗口

> 完整模板（七张）与全部题解清单见 [slide_window_template.md](slide_window_template.md)。

其基本的思想是初始化窗口
- insert
- update 
- delete

代码骨架（`right < k-1` 是灵魂，它保证统计时窗口长度恰好为 k）：

```cpp
for (int right = 0; right < n; right++) {
    sum += nums[right];                  // 1. insert
    if (right < k - 1) continue;         // 窗口未满
    ans = max(ans, sum);                 // 2. update
    sum -= nums[right - k + 1];          // 3. delete
}
```

### 一、模板套用即可
643、1343、1456、2379、2090、2269、1052、1176（k 天总和与 lower/upper 比打分）、2461（额外要求窗口内元素互不相同）、2841（额外要求至少 m 种）、219（窗口内查重复值，用哈希集合）

### 二、同样是模板，但是注意索引的位置即可
2090（窗口长 2k+1，半径两端不足填 -1）、1343（先 threshold×k 免除法）

### 三、定长 + 字符计数比较
438（记录所有起点）、567（命中即 return）、30（按 wordLen 分组滑）

### 四、环形定长
2134：1 的总个数就是窗口长，`right` 走 `[0, 2n)`、取值 `right % n`
1151：2134 的非环形版，窗口长 = 1 的个数，数窗口内 0 的最少个数
1652：环形，k>0 取后 k 个和、k<0 取前 -k 个和（相邻 i 的窗口只挪一格）
