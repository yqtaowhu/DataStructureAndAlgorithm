while (right < s.size()) {
    // 增大窗口
    window.add(s[right]);
    right++;

        // 缩小窗口
        window.remove(s[left]);
        left++;
    }
}


# 不定长滑动窗口

> 完整模板（七张）、六个高频坑与全部题解清单见 [slide_window_template.md](slide_window_template.md)。

一般有至多、至少子串，子数组等

### 一、至多 k 个 → 求最长（模板一：入 → 收缩 → 更新）
- 最多 k 个重复元素：2958、3090、1493（有细微变化，答案是 `right-left`）
- 最多 k 个 0 / 另一种字符：1004、2024、424
- 最多 k 种类型：904（数组版，k=2）、[159](0159.至多包含两个不同字符的最长子串.cpp)（字符串版，k=2）、[340](0340.至多包含k个不同字符的最长子串.cpp)（k 任意；159/340 为会员题）
- 预算型（Σcost ≤ maxCost）：1208
- 逆向转化：1658（中间和为 total-x 的最长窗口）

### 二、至少满足某条件 → 求最短（模板二：边出边更新）
- 209（和 ≥ target）
- 76（覆盖子串，need/window/valid）
- 2904（最短 + 字典序最小）
- 2260（窗口内出现重复值）
- 862：**含负数，普通滑窗失效**，用前缀和 + 单调队列

### 三、求个数（模板四：每轮累加）
- 窗口越短越合法 ⇒ `ans += right - left + 1`：713
- 窗口越长越合法 ⇒ 收缩到刚好不合法后 `ans += left`：1358
- 覆盖型计数：3697 / 3698
