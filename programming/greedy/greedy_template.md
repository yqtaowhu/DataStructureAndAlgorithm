# 贪心算法 C++ 模板（分类型速记版）

## 核心思想：每一步都做局部最优，从而推出全局最优

贪心没有统一代码模板，但有统一的**思维套路**。解题三步：

1. **找贪心点**：把大问题拆成若干子问题，找到每一步的「局部最优选择」是什么。
2. **证无后效**：证明局部最优能推出全局最优（面试可用「反证法 / 交换论证」口述，无需严格证明）。
3. **套分类模板**：贪心题几乎都能归入下面六大类，认清类别即可套模板。

> 贪心 vs 动态规划：贪心**每步不回头的做一次决定**（自顶向下），DP 需要**比较多种选择**（自底向上）。
> 判断能否贪心的关键：当前选择是否会「堵死」后面更优的可能。若不会 → 贪心；若会 → DP。

## 万能模板一：区间贪心（按端点排序后一次扫描）

适用：区间重叠、覆盖、合并、最少箭/最少区间问题。**核心是选对排序键**。

```cpp
// 排序键决定一切：
// - 求「最多不重叠区间 / 最少箭」  -> 按【右端点】升序
// - 求「合并区间 / 覆盖」         -> 按【左端点】升序
sort(intervals.begin(), intervals.end(),
     [](const vector<int>& a, const vector<int>& b) {
         return a[1] < b[1];   // 按右端点
     });

// 示例：435 无重叠区间 / 452 引爆气球（右端点贪心）
int res = 0, tail = intervals[0][1];   // tail = 上一个保留区间的右端点
for (int i = 1; i < n; i++) {
    if (intervals[i][0] < tail)  res++;          // 重叠 -> 删除/一箭带走
    else  tail = intervals[i][1];                // 不重叠 -> 更新右端点
}
```

**要点：** 「按右端点排序 + 尽量保留右端点小的」能给后面留最多空间，这是所有区间贪心的通用直觉。

## 万能模板二：跳跃贪心（维护当前能到达的最远边界）

适用：跳跃游戏、最少跳跃次数、能否到达终点。

```cpp
// 示例：55 跳跃游戏（能否到达）
int maxFar = 0;
for (int i = 0; i < n; i++) {
    if (maxFar < i) return false;        // i 已经超出可达范围，失败
    maxFar = max(maxFar, i + nums[i]);   // 刷新最远可达
    if (maxFar >= n - 1) return true;    // 提前到达终点
}
return true;

// 示例：45 跳跃游戏 II（最少步数）——分层 BFS 思想
int maxFar = 0, end = 0, step = 0;
for (int i = 0; i < n - 1; i++) {        // 注意 i 到 n-2，避免终点多跳一次
    maxFar = max(maxFar, i + nums[i]);
    if (i == end) { end = maxFar; step++; }  // 走到本层边界 -> 必须跳一步
}
```

## 万能模板三：分配/交换贪心（排序后双指针配对）

适用：分发饼干、分发糖果、种花、找零、两地调度——「把资源最优地分给需求」。

```cpp
// 示例：455 分发饼干（小的先喂小的）
sort(g.begin(), g.end());   // 胃口
sort(s.begin(), s.end());   // 饼干
int i = 0, j = 0;
while (i < g.size() && j < s.size()) {
    if (g[i] <= s[j]) i++;   // 当前饼干能满足当前孩子 -> 孩子 +1
    j++;                     // 无论如何饼干指针都前进
}
return i;
```

**要点：** 排序把「谁配谁」的最优决策变成一次线性扫描；分配问题常需**两个方向各扫一遍**（如 135 分发糖果）。

## 万能模板四：股票买卖贪心（收集所有正收益）

适用：不限交易次数 / 含手续费的股票买卖。

```cpp
// 示例：122 买卖股票最佳时机 II（可多次买卖，贪心收集每一段涨幅）
int profit = 0;
for (int i = 1; i < n; i++)
    profit += max(0, prices[i] - prices[i - 1]);   // 只吃上涨的部分
```

> 121 只能买卖一次 → 维护「历史最低价」；714 含手续费 → 用「持有/不持有」两个状态贪心转移。

## 万能模板五：单调栈贪心（求字典序最值）

适用：移掉 K 位数字、去除重复字母、拼接最大数——「删/留字符使结果字典序最小或最大」。

```cpp
// 示例：402 移掉 K 位数字（删掉「峰值」使字典序最小）
string stk;
for (char c : num) {
    while (k > 0 && !stk.empty() && stk.back() > c) {  // 栈顶比当前大 -> 删栈顶
        stk.pop_back(); k--;
    }
    stk.push_back(c);
}
while (k > 0) { stk.pop_back(); k--; }   // 还有剩余配额，从末尾删
// 再去前导零；若为空返回 "0"
```

**要点：** 保持栈内单调，遇到「破坏单调性」的元素就贪心地删，删够 K 个为止。

## 万能模板六：调度/堆贪心（优先级队列决定先做谁）

适用：任务调度器、重构字符串、课程表 III、最低加油次数、Dota2 参议院。

```cpp
// 示例：621 任务调度器（贪心公式法，无需堆）
// 出现次数最多的任务 maxCnt 个，有 (maxCnt-1) 个「间隔槽」，每槽长 n+1
int maxCnt = 0;
for (int c : cnt) maxCnt = max(maxCnt, c);
int slots = (maxCnt - 1) * (n + 1) + count(cnt.begin(), cnt.end(), maxCnt);
return max((int)tasks.size(), slots);   // 任务种类多到填满时，直接取任务总数
```

**要点：** 「每一步选当前最优的那个」通常用**大顶堆**实现（取频次最高 / 油量最多 / 截止时间最晚）。

## 记忆口诀

> **区间排序看端点，跳跃维护最远边；**
> **分配先把序排好，股票只吃上涨段；**
> **字典序题用单调栈，调度难题上大顶堆。**
> 每做一步都要问：这个局部最优，会不会堵死后面的全局最优？不会才敢贪。
