# 双指针 C++ 模板（简单易记版）

## 核心思想：用两个下标代替两层循环

双指针的本质是利用**单调性**，把暴力解法 `O(n^2)` 的两层循环优化为一次扫描 `O(n)`：
- 两个指针**各走各的路**，但每一次移动都**排除掉一批不可能的解**
- 指针只前进不后退，总移动次数不超过 `2n`

按指针运动方向分三类：**对撞指针、同向指针、快慢指针**。

## 万能模板一：对撞指针（left 从左，right 从右）

适用前提：**有序**（或一个数组的两端），问题形如"找两个数 / 判断回文"。

```cpp
// 示例：167. 两数之和 II - 输入有序数组
vector<int> twoSum(vector<int>& numbers, int target) {
    int left = 0, right = numbers.size() - 1;
    while (left < right) {                       // 相遇即停
        int sum = numbers[left] + numbers[right];
        if (sum == target)  return {left + 1, right + 1}; // 找到答案
        else if (sum < target) left++;      // 和太小，只有左指针右移才能变大
        else right--;                       // 和太大，只有右指针左移才能变小
    }
    return {};
}
```

**只需记住三句话：**
1. `left` 从 0 出发，`right` 从 `n-1` 出发，循环条件 `left < right`
2. 小了 `left++`，大了 `right--`（移动的依据：另一边怎么动都不会更接近）
3. 每次移动都**淘汰一个元素**，所以是 `O(n)`

## 万能模板二：同向双指针（原地去重 / 移除元素）

适用：**原地修改数组**，快指针找新元素，慢指针管写入位置。

```cpp
// 示例：26. 删除有序数组中的重复项（283. 移动零 同款）
int removeDuplicates(vector<int>& nums) {
    int slow = 0;                                // slow：下一个该写入的位置
    for (int fast = 0; fast < nums.size(); fast++) {
        if (nums[fast] != nums[slow]) {          // fast 找到一个新元素
            nums[++slow] = nums[fast];           // 写入，保留区间 [0, slow]
        }
    }
    return slow + 1;
}
```

**要点：** 慢指针左边永远是"处理好的结果"，快指针负责探路；"移除元素"就是把判断条件换成 `nums[fast] != val`。

## 万能模板三：快慢指针（链表中点 / 判环）

适用：链表找中点、判环、找环入口。

```cpp
// 示例：141. 环形链表 / 876. 链表的中间结点
ListNode *slow = head, *fast = head;
while (fast && fast->next) {
    slow = slow->next;          // 慢指针一次一步
    fast = fast->next->next;    // 快指针一次两步
}
// 循环结束：奇数个节点 slow 是中点，偶数个是右中点
// 若有环：fast 会追上 slow（slow == fast），无环则 fast 走到 nullptr
```

> 142. 找环入口：相遇后把 slow 拉回 head，两指针同速前进，再相遇处即入口（数学可证）。

## 记忆口诀

> **对撞：小了左走大右走；同向：快探路慢插旗；快慢：两倍速必追上。**
> 每次移动都要问自己：这一步淘汰了哪些不可能的解？
