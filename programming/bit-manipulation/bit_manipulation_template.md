# 位运算 C++ 模板（简单易记版）

## 核心思想：把整数看成 32 个开关 / 一个集合

位运算题的本质只有两个视角：
- **开关视角**：每一位是 0/1，单点操作就是置位、清位、取反、读位
- **集合视角**：一个 int 是一个最多 32 个元素的集合，`&` 是交集、`|` 是并集、`^` 是对称差、`~` 是补集

按套路分六类：**基础位操作、n&(n-1) 与 lowbit、异或消去律、逐位统计、掩码（集合）思想、与/或子数组（log trick）**。

## 万能模板一：基础位操作速查

所有位运算题的地基，必须形成肌肉记忆。

```cpp
// 以第 i 位（从 0 开始）为对象
(x >> i) & 1          // 读第 i 位
x | (1 << i)          // 第 i 位置 1
x & ~(1 << i)         // 第 i 位清 0
x ^ (1 << i)          // 第 i 位取反

x & 1                 // 判奇偶：1 奇 0 偶
(x & (x - 1)) == 0    // 判断 2 的幂（x > 0）
x & -x                // 取 lowbit：只保留最低位的 1（可作分组标记）
x >> i << i           // 把第 i 位以上清零，保留下 i 位
~0u << i              // 高位掩码（注意用 unsigned 避免 UB）

a ^= b; b ^= a; a ^= b;   // 不用临时变量交换（面试趣味题，实战用 swap）
```

**要点：**
1. 移位、与或非的组合能表达一切"对某一位/某一段"的操作
2. 带符号数右移是算术移位，对可能为负的数先转 `unsigned` 或用 `uint32_t`
3. `1 << i` 中 `i >= 31` 时会溢出成负数，用 `1u` 或 `1LL` 规避

## 万能模板二：n & (n - 1) 与 lowbit

`n & (n - 1)`：**抹掉最低位的 1**。`n & -n`：**只留最低位的 1**。两者互为补运算。

```cpp
// 示例：191. 位 1 的个数
int hammingWeight(uint32_t n) {
    int res = 0;
    while (n) {
        n &= (n - 1);   // 每循环一次抹掉一个 1，循环次数 = 1 的个数
        res++;
    }
    return res;
}
// 一行版：__builtin_popcount(n)
```

**只需记住三句话：**
1. 抹 1 用 `n & (n - 1)`，取 1 用 `n & -n`
2. 判断"是 2 的幂""统计 1 的个数""逐个消灭 1"都靠它
3. range 按位与（201）：`m != n` 时不断同时右移，公共前缀就是答案

## 万能模板三：异或消去律（找"只出现一次"家族）

`a ^ a = 0`，`a ^ 0 = a`，且异或满足交换律结合律 —— 全体异或后，成对的全部抵消。

```cpp
// 示例：136. 只出现一次的数字（其余都出现两次）
int singleNumber(vector<int>& nums) {
    int res = 0;
    for (auto &n : nums) res ^= n;   // 抵消后剩下唯一的数
    return res;
}
```

**变体如何改：**
- **260. 其余出现两次、两个数出现一次**：全体异或得 `x ^ y`，取 `lowbit` 按"该位是 0 还是 1"把数组分成两组，各组内再异或
- **137. 其余出现三次、一个数出现一次**：换成逐位统计（模板四），`count % 3` 拼回答案

## 万能模板四：逐位统计（"每一位单独看"）

把整数拆成 32 位，**每一位独立统计**，常用于模某个数、排序键、计数。

```cpp
// 示例：137. 只出现一次的数字 II（其余都出现三次）
int singleNumber(vector<int>& nums) {
    int ans = 0;
    for (int bit = 0; bit < 32; bit++) {
        int cnt = 0;
        for (int x : nums) cnt += (x >> bit) & 1;  // 统计该位 1 的个数
        ans += (cnt % 3) << bit;                    // 模 3 后拼回
    }
    return ans;
}
```

**要点：**
1. 套路 = 外层枚举位、内层统计 `(x >> bit) & 1`，按条件拼答案
2. 统计 `[0, n]` 每个数的 1 的个数可用 DP：`bit[i] = bit[i >> 1] + (i & 1)`（1356）
3. 汉明距离 = `__builtin_popcount(x ^ y)`（461）；多数元素也可逐位统计"超过一半"（169）

## 万能模板五：掩码（集合）思想

一个 int 当一个集合用：字母表 26 个字母 → 26 个开关；`k` 的二进制位 → 一个子集。

```cpp
// 示例：面试题 01.01. 判断字符是否唯一（int 掩码代替 bool 数组）
bool isUnique(string astr) {
    int mask = 0;
    for (char c : astr) {
        int bit = 1 << (c - 'a');
        if (mask & bit) return false;   // 交集非空 → 重复
        mask |= bit;                    // 并集：加入集合
    }
    return true;
}
```

**集合语言速查：**
| 判断/操作 | 位运算 |
|-----------|--------|
| 子集：`k ⊆ n` | `(n & k) == k` |
| 交集非空 | `(a & b) != 0` |
| 差集（n 删掉 k 剩什么） | `n ^ k`（k ⊆ n 时） |
| 求差集元素个数 | `__builtin_popcount(n ^ k)` |
| 枚举非空子集 | `for (int s = x; s; s = (s - 1) & x)` |

- 3226. 使两个整数相等的位更改次数 = 判子集 + 差集元素个数
- 318. 最大单词长度乘积、421. 数组中两个数的最大异或值也是掩码思想的经典题

## 万能模板六：与/或子数组（log trick，固定右端点）

关键结论：以 `i` 为右端点的所有子数组的与/或值，**只有 O(log V) 种**（与/或的结果单调，每多合并一个数二进制高位只会单向变化）。实现上从右往左**原地合并**，值不再变化就提前停止。

```cpp
// 示例：3171. 找到按位或最接近 K 的子数组（3097 / 1521 同款，改 OR 为 AND）
int minimumDifference(vector<int>& nums, int k) {
    int ans = INT_MAX;
    for (int i = 0; i < (int)nums.size(); i++) {
        int tmp = nums[i];
        ans = min(ans, abs(tmp - k));
        // 逆序合并：若 nums[j] | tmp == nums[j]，说明再往上 OR 结果不变，可停
        for (int j = i - 1; j >= 0 && (nums[j] | tmp) != nums[j]; j--) {
            nums[j] |= tmp;                     // nums[j] 变为子数组 [j, i] 的 OR
            ans = min(ans, abs(nums[j] - k));
        }
    }
    return ans;
}
```

**要点：**
1. 固定右端点 `i`，逆序枚举左端点 `j`，用 `nums[j]` 原地存 `[j, i]` 的累积与/或
2. 终止条件：本次合并后值不变（`(nums[j] | tmp) == nums[j]`），保证复杂度 O(n log V)
3. 2419. 按位与最大的最长子数组是它的贪心简化版：与的最大值就是数组最大值，只数最长连续段

## C++ 内建函数速查（编译器自带，竞赛与刷题神器）

| 函数 | 作用 | 等价手写 |
|------|------|----------|
| `__builtin_popcount(x)` | 1 的个数 | 循环 `n &= n-1` |
| `__builtin_ctz(x)` | 末尾 0 的个数（lowbit 位置） | `lowbit = x & -x` |
| `__builtin_clz(x)` | 前导 0 的个数 | 结合 32 可求位宽 |
| `bit_width((uint32_t) x)` | 二进制宽度（C++20） | 循环右移计数 |
