# 回溯 C++ 模板（简单易记版）

## 核心思想：决策树上的深度优先遍历

回溯 = **穷举所有可能**，但用"走错了就退回来"的方式避免重复建数据结构。
把整个搜索过程想象成一棵**决策树**：
- 每一层做一个选择（树枝）
- 走到叶子（满足条件）就收集结果
- 递归返回后**撤销选择**（恢复现场），尝试下一个分支

> 更细的题型讲解见 [回溯题型总结.md](回溯题型总结.md)，只是缺少统一模板时，看这一篇就够。

## 万能模板（背这一个骨架）

```cpp
vector<vector<int>> res;    // 收集所有结果
vector<int> path;           // 当前路径

void backtrack(vector<int>& nums, int start) {
    // 1. 终止条件：path 满足要求就收集（子集题不用 return，边走边收）
    res.push_back(path);

    // 2. 本层选择列表：从 start 开始，避免重复
    for (int i = start; i < nums.size(); i++) {
        // 3. 剪枝：跳过不合法的选择
        if (i > start && nums[i] == nums[i - 1]) continue; // 树层去重

        path.push_back(nums[i]);        // 4. 做选择
        backtrack(nums, i + 1);         // 5. 递归下一层
        path.pop_back();                // 6. 撤销选择（回溯！）
    }
}
```

**只需记住三句话：**
1. 循环前判断终止、收集结果
2. 循环内「做选择 → 递归 → 撤销选择」三部曲
3. 用 `start` 控制下一层的选择起点，保证"组合"不重复

## 组合 / 排列 / 子集三兄弟：只改两行

三者共用同一个骨架，区别只有 **start 的传法** 和 **收集时机**：

| 题型 | 递归传参 | 收集时机 | 典型题 |
|------|----------|----------|--------|
| **子集** | `i + 1` | **每个节点**都收集（进函数就收） | 78 / 90 / 1836 |
| **组合** | `i + 1` | 终止条件满足时收（如 path.size()==k） | 77 / 39 / 40 / 216 |
| **排列** | 全部可选，**不传 start**（用 used 数组） | path.size()==n 时收 | 46 / 47 |

```cpp
// 排列版骨架（46. 全排列）：每层都能从 0 开始选
void backtrack(vector<int>& nums, vector<bool>& used) {
    if (path.size() == nums.size()) { res.push_back(path); return; }
    for (int i = 0; i < nums.size(); i++) {
        if (used[i]) continue;              // 选过的跳过
        used[i] = true;  path.push_back(nums[i]);
        backtrack(nums, used);
        used[i] = false; path.pop_back();
    }
}
```

> 记忆：**「同层去重，同枝可重」**——同一层跳过重复值，同一条路径允许重复选择。

## 记忆口诀

> **递归三问**：终止条件是什么？本层有哪些选择？选择之后怎么撤销？
> **子集进就收，组合数够收，排列装满收；同层去重要排序，可重选择传 i 不传 i+1。**
